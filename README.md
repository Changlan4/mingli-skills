# 命理技能：六爻 · 八字

> 两个给 AI Agent 用的命理技能。
>
> 核心只有一句话：**能算的交给脚本，该查的指回原书，结论必须能指到章节。**

## 免责声明

- 本项目仅供娱乐、文化研究与技术演示。
- 命理属于传统文化范畴，其结论无法被科学验证，本项目不承诺任何准确性。
- 不构成医疗、法律、投资、婚姻等任何专业建议，请勿据此做重大决定。
- 请相信科学，理性看待。

任何模型都能跟你聊六爻八字。问题在于它是怎么聊的：

| 常见做法 | 后果 |
|---|---|
| 让模型"看着爻象推" | 干支、纳甲、世应、六亲错一位，整卦作废——而且错得毫无提示 |
| 规则凭记忆 | 同一卦问两次，两次结论不一样 |
| 结论不标出处 | 你无法核对，也分不清哪句是书里的、哪句是模型编的 |

这两个技能把这三件事分别钉死：

1. **排盘由脚本算。** 六爻的纳甲 / 世应 / 六亲 / 六神 / 旬空 / 伏神，八字的四柱 / 藏干 / 十神 / 纳音 / 空亡 / 大运 / 起运 / 神煞，一律 Python 计算，模型只负责解读。
2. **断法有固定纪律。** 六爻分「吉凶判断层面」与「应期细节层面」两层断——同一条理论在两层结论可以相反，混用必错；八字按「强弱 → 调候 → 格局 → 刑冲 → 形象 → 动态 → 神煞」固定顺序走，不许跳步。
3. **结论能追溯。** 每条判断标出章节或页码，书里没有的明说"原书未及"，不许用网络通说补足。

## 两个技能

### `liuyao/` — 六爻纳甲

依据朱辰彬《古筮真诠》（总论篇 · 易理篇，40 章）。

- **排盘**：摇卦结果（`7 8 9 6 7 8`）、铜钱正反、或阴阳，直接出本卦/变卦、宫位、世应、纳甲、六亲、六神、旬空、伏神。
- **解析别人排好的盘**：把别的软件输出的盘面粘进去，引擎重新排一遍，再与原文**逐项对账**，抓出"干支阴阳不配""世应错位""六亲与纳甲矛盾"这类错误，把冲突点摆出来，而不是硬着头皮解。
- **判定引擎**：`judge.py` 做两件事——按六步次序取用神（世应优先 → 有动取动 → 有异取异 → 唯一 → 日月 → 伏神），以及按层面隔离出吉凶结论与应期候选。输出带断言表，每条标 `[id][层面]` 与原文出处。
- **应期**：24 条公式 + 四档日月转换（短事按日 / 常事按月 / 久远按年 / 日内按时辰），区分 25 项层面差异。

### `bazi/` — 八字（陆致极体系）

依据陆致极《八字命理学》基础、进阶、动态教程三本。

- **排盘**：公历或农历，自动查城市经度做**真太阳时**校正，处理早子时 / 晚子时两种流派；输出四柱、藏干、十神、纳音、星运、自坐、神煞、旬空、五行分布、大运与起运时间。
- **对账**（最高频也最值钱）：把别人软件的盘粘进来，抠出四柱与大运 → 引擎重算 → 逐项比对。能抓五鼠遁不配套、大运错位一格、十神或藏干错误、大运顺逆反了、起运岁数偏了。
- **解盘**：六视角分工与冲突排序，`07-断事纪律.md` 里的"先问后断""禁用模糊词""三分标注（已确认 / 先前推断 / 本次补推）"。

## 怎么装

**不用懂命令行。** 把下面这段话整段复制，粘给你正在用的 AI（Claude Code、ZCode、Cursor 都行），按回车：

> 帮我装一下这个技能：https://github.com/Changlan4/mingli-skills
> 把仓库里的 liuyao 和 bazi 两个目录放进你的 skills 目录，装好 lunar-python 和 sxtwl 两个依赖，然后跑一遍测试确认能跑。

它会自己下载、放好、装依赖、跑测试。你只需要看最后有没有出现「通过 18 项，失败 0 项」和「通过 123 项，失败 0 项」。

如果你的 AI 不会自己装，就手动把仓库里 `liuyao`、`bazi` 两个文件夹整个复制进技能目录。Claude Code 的是 `~/.claude/skills/`，ZCode / DSH 这类是 `~/.agents/skills/`；还是找不到，就把仓库链接丢给你的 AI，让它帮你放。

## 怎么用

装好之后不用记任何命令，直接说话就行。

**问六爻**，把摇卦结果告诉它：

> 我摇了一卦，从下往上是 7 8 9 6 7 8，时间是今天上午十点半，问这个项目该不该接。

**问八字**，把出生时间告诉它：

> 1990 年 6 月 15 日上午 10 点，男的，生在上海，帮我看看。

**核对别人排的盘**，把盘面原样粘过去：

> 这是我用别的软件排的盘，帮我看看排错没有。
> （粘贴盘面）

它会先用脚本把盘算一遍，再解读。排盘这一步不许自己估。

**它会问你几件事，别嫌烦：**

- 六爻：问的是什么事、这件事大概多长周期（这个月内？今年内？）。周期说不清，应期就断不准。
- 八字：出生地（要校正真太阳时）、性别，还有上过什么学、哪年开始工作这类前提。断到具体年份必须用到。

## 它是怎么被验证的

两个技能各带一组回归测试：六爻 18 项，八字 123 项。

测的都是硬指标——干支排得对不对、藏干对不对、大运顺不顺、起运岁数准不准。这些错了，后面解什么都白搭。

测试的参照全部来自原书里记载的命例，另外加了 2000 年立春这个分界时刻来卡边界。改动任何一行逻辑，跑一遍测试，错一项就不发版。

文档里所有命例一律用「命例甲 / 命例乙 / 命例丙……」代指，不出现任何真实姓名。书里怎么称呼这些人，请对照你手上的原书。
