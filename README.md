# 命理技能：六爻 · 八字

> 两个给 AI Agent 用的命理技能。
>
> 核心只有一句话：**能算的交给脚本，该查的指回原书，结论必须能指到章节。**

## 三十秒搞懂这两个词

**六爻**：心里有件具体的事拿不定主意，摇六次硬币得到一个卦，用卦来看这件事的走向。它问的是「这一件事」——这个项目接不接、这次面试能不能过、这个人还联不联系。

**八字**：把一个人出生的年、月、日、时换算成八个字，用这八个字看这个人整体的走势。它问的是「这个人」——性格、事业方向、哪年容易有变动。

一句话记：**六爻问一件事，八字看一辈子。**

这两样是旧东西了。这个仓库做的不是"算命神器"，而是把其中**能算准的部分**（排盘）交给代码，剩下说不准的部分交给 AI 按规矩讲。规矩对不对，你随时可以拿书核。

任何模型都能跟你聊六爻八字。问题在于它是怎么聊的：

| 常见做法 | 后果 |
|---|---|
| 让模型"看着爻象推" | 干支、纳甲、世应、六亲错一位，整卦作废——而且错得毫无提示 |
| 规则凭记忆 | 同一卦问两次，两次结论不一样 |
| 结论不标出处 | 你无法核对，也分不清哪句是书里的、哪句是模型编的 |

这两个技能把这三件事分别钉死：

1. **排盘由脚本算。** 六爻的纳甲 / 世应 / 六亲 / 六神 / 旬空 / 伏神，八字的四柱 / 藏干 / 十神 / 纳音 / 空亡 / 大运 / 起运 / 神煞，一律 Python 计算，模型只负责解读。
2. **断法有固定纪律。** 六爻分「吉凶判断层面」与「应期细节层面」两层断——同一条理论在两层结论可以相反，混用必错；八字按「强弱 → 调候 → 格局 → 刑冲 → 形象 → 动态 → 神煞」固定顺序走，不许跳步。
3. **结论能追溯。** 每条判断标出章节或页码，书里没有的明说"原书未及"，不许用网络通说补足。

## 两个技能

### `liuyao/` — 六爻纳甲

依据朱辰彬《古筮真诠》（总论篇 · 易理篇，40 章）。

- **排盘**：铜钱背数、阴阳、或排盘软件的 6/7/8/9，直接出本卦/变卦、宫位、世应、纳甲、六亲、六神、旬空、伏神。
- **解析别人排好的盘**：把别的软件输出的盘面粘进去，引擎重新排一遍，再与原文**逐项对账**，抓出"干支阴阳不配""世应错位""六亲与纳甲矛盾"这类错误，把冲突点摆出来，而不是硬着头皮解。
- **判定引擎**：`judge.py` 做两件事——按六步次序取用神（世应优先 → 有动取动 → 有异取异 → 唯一 → 日月 → 伏神），以及按层面隔离出吉凶结论与应期候选。输出带断言表，每条标 `[id][层面]` 与原文出处。
- **应期**：24 条公式 + 四档日月转换（短事按日 / 常事按月 / 久远按年 / 日内按时辰），区分 25 项层面差异。

### `bazi/` — 八字（陆致极体系）

依据陆致极《八字命理学》基础、进阶、动态教程三本。

- **排盘**：公历或农历，自动查城市经度做**真太阳时**校正，处理早子时 / 晚子时两种流派；输出四柱、藏干、十神、纳音、星运、自坐、神煞、旬空、五行分布、大运与起运时间。
- **对账**（最高频也最值钱）：把别人软件的盘粘进来，抠出四柱与大运 → 引擎重算 → 逐项比对。能抓五鼠遁不配套、大运错位一格、十神或藏干错误、大运顺逆反了、起运岁数偏了。
- **解盘**：六视角分工与冲突排序，`07-断事纪律.md` 里的"先问后断""禁用模糊词""三分标注（已确认 / 先前推断 / 本次补推）"。

## 怎么装

**不用懂命令行。** 把下面这段话整段复制，粘给你正在用的 AI（Claude Code、ZCode、Cursor 都行），按回车：

> 帮我装一下这个技能：https://github.com/Changlan4/mingli-skills
> 把仓库里的 liuyao 和 bazi 两个目录放进你的 skills 目录，装好 lunar-python 和 sxtwl 两个依赖，然后跑一遍测试确认能跑。

它会自己下载、放好、装依赖、跑测试。你只需要看最后有没有出现「通过 18 项，失败 0 项」和「通过 123 项，失败 0 项」。

如果你的 AI 不会自己装，就手动把仓库里 `liuyao`、`bazi` 两个文件夹整个复制进技能目录。Claude Code 的是 `~/.claude/skills/`，ZCode / DSH 这类是 `~/.agents/skills/`；还是找不到，就把仓库链接丢给你的 AI，让它帮你放。

## 怎么用

装好之后不用记任何命令，直接说话就行。

### 问六爻：先摇卦，再发它

没摇过也没关系，四步：

1. **找三枚一样的硬币**。五毛、一元、铜钱都行，三枚大小要一样。
2. **合在手心晃几下，撒在桌上**，数一下几个**花面朝上**，记下来。
3. **连做六次**。第一次的结果记在最下面，第六次记在最上面——顺序反了，整个卦就变了。
4. **把六个数字发过去**，再补上时间和你要问的事。

> 我摇了六次硬币，从下往上，每次花面朝上的个数是 1、2、3、0、1、2。时间是今天上午十点半，问这个项目该不该接。

记法它认得几种，你用顺手的就行：数花面（上面这种）、写阴阳（「阳、阴、阳动、阴、阳、阴」）、或者别的排盘软件给出的 6/7/8/9。实在懒得记，用手机上的摇卦小程序摇完，把结果贴过去也一样。

### 问八字：报四样东西

| 要什么 | 怎么给 |
|---|---|
| 出生年月日 | **阳历**就行。你记的是农历也没关系，加一句「农历」，它会自己换算 |
| 出生时间 | 几点几分。只知道大概几点也能排，但时柱可能不稳；完全不知道时辰，只能排三柱，很多结论做不了 |
| 出生地点 | 省市就够。这关系到「真太阳时」——同一个钟点，北京和乌鲁木齐的太阳位置能差一两个小时，不校正时柱就会错 |
| 性别 | 男女的大运方向是反的，这个不能猜 |

> 1990 年 6 月 15 日上午 10 点，男的，生在上海，帮我看看。

不知道出生地，就直说「不知道」，它会跳过校正并告诉你结果可能偏在哪。

**核对别人排的盘**，把盘面原样粘过去：

> 这是我用别的软件排的盘，帮我看看排错没有。
> （粘贴盘面）

它会先用脚本把盘算一遍，再解读。排盘这一步不许自己估。

**它会问你几件事，别嫌烦：**

- 六爻：问的是什么事、这件事大概多长周期（这个月内？今年内？）。周期说不清，应期就断不准。
- 八字：出生地（要校正真太阳时）、性别，还有上过什么学、哪年开始工作这类前提。断到具体年份必须用到。

## 它是怎么被验证的

两个技能各带一组回归测试：六爻 18 项，八字 123 项。

测的都是硬指标——干支排得对不对、藏干对不对、大运顺不顺、起运岁数准不准。这些错了，后面解什么都白搭。

测试的参照全部来自原书里记载的命例，另外加了 2000 年立春这个分界时刻来卡边界。改动任何一行逻辑，跑一遍测试，错一项就不发版。

文档里所有命例一律用「命例甲 / 命例乙 / 命例丙……」代指，不出现任何真实姓名。书里怎么称呼这些人，请对照你手上的原书。

## 关于原书（必读）

**本仓库不包含原书正文。**

两个技能的方法论依据是：

- 朱辰彬《古筮真诠》（总论篇 · 易理篇），40 章
- 陆致极《八字命理学基础教程》《进阶教程》《动态分析教程》

两部书都受版权保护，所以仓库里只放**自己整理的方法论卡片与章节索引**，不放原文。

### 为什么索引里没有页码

因为页码靠不住。同一本书，印刷版、扫描版、不同 PDF 软件导出的页码能差几十页。写死一个页码，读者拿着自己的版本去翻，十有八九翻错地方。

所以索引按**章节标题**定位：`《八字命理学基础教程》· 第五章 结构分析（2） 十干和调候`。标题跨版本基本不变，翻目录就能找到。

### AI 读不了纸质书

书拿在手里，AI 看不到。要让它按「第 28 章」真正翻到旬空那一段，得把电子文本放进 `references/`：

- 六爻：按章拆成 `chNN.md`
- 八字：按原书章节名放

放对了，索引里的标题直接能对上。

### 想用自己的版本精确到页

仓库带了个小脚本：

```
python tools/make_pagemap.py 我的书.txt
```

它会扫描你导出的文本，生成一份 `pagemap.json`，记下每一章在你这份文件里的页码。之后引用就能落到你自己的版本上。**书不经过仓库，只在你本机跑。**

### 没有电子版也能用

精度打折而已：技能靠规则卡判断，引用只能标到章节号，具体原文你得自己翻。排盘这部分完全不受影响。

## 边界

- **仅供娱乐与文化研究。** 命理无法被科学验证，本项目不承诺预测效力，也不建议把它当作决策依据。请相信科学，理性看待。
- **不承诺准确。** 命理是解释框架，不是事实判断。技能里反复强调"从卦象看""倾向于"，不用"必然""注定"。
- **不替你做重大决定。** 婚姻、疾病、投资、诉讼，只谈倾向与压力点，以专业意见为准。
- **书里没有的不硬凑。** 合婚、择日、风水、西洋占星、对方长相职业籍贯，明确说超出范围。
- **不预测彩票、不代占生死。** 情绪低落或问生死时，语气要收敛。

## 看不懂的词查这里

| 它说的词 | 人话 |
|---|---|
| 排盘 | 把卦或者八字一格一格算出来，摆成一张表 |
| 起卦 / 摇卦 | 摇六次硬币，把结果记下来，换算成一个卦 |
| 用神 | 这个卦里代表「你问的那件事」的那一爻 |
| 世爻 / 应爻 | 卦里代表「你自己」和「对方」的两爻 |
| 旬空 | 某一爻暂时空着、使不上劲，要等它出空 |
| 应期 | 这件事大概什么时候应验 |
| 大运 | 十年一段的运势，八字按十年切 |
| 流年 | 具体某一年 |
| 真太阳时 | 按太阳实际位置算的时间，不是手表上的北京时间 |
| 对账 | 别人排好的盘，重新算一遍，看有没有错 |
