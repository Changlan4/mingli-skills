# 命理技能：六爻 · 八字

> 两个给 AI Agent 用的命理技能。
>
> 核心只有一句话：**能算的交给脚本，该查的指回原书，结论必须能指到章节。**

## 免责声明

- 本项目仅供娱乐、文化研究与技术演示。
- 命理属于传统文化范畴，其结论无法被科学验证，本项目不承诺任何准确性。
- 不构成医疗、法律、投资、婚姻等任何专业建议，请勿据此做重大决定。
- 请相信科学，理性看待。

任何模型都能跟你聊六爻八字。问题在于它是怎么聊的：

| 常见做法 | 后果 |
|---|---|
| 让模型"看着爻象推" | 干支、纳甲、世应、六亲错一位，整卦作废——而且错得毫无提示 |
| 规则凭记忆 | 同一卦问两次，两次结论不一样 |
| 结论不标出处 | 你无法核对，也分不清哪句是书里的、哪句是模型编的 |

这两个技能把这三件事分别钉死：

1. **排盘由脚本算。** 六爻的纳甲 / 世应 / 六亲 / 六神 / 旬空 / 伏神，八字的四柱 / 藏干 / 十神 / 纳音 / 空亡 / 大运 / 起运 / 神煞，一律 Python 计算，模型只负责解读。
2. **断法有固定纪律。** 六爻分「吉凶判断层面」与「应期细节层面」两层断——同一条理论在两层结论可以相反，混用必错；八字按「强弱 → 调候 → 格局 → 刑冲 → 形象 → 动态 → 神煞」固定顺序走，不许跳步。
3. **结论能追溯。** 每条判断标出章节或页码，书里没有的明说"原书未及"，不许用网络通说补足。

## 两个技能

### `liuyao/` — 六爻纳甲

依据朱辰彬《古筮真诠》（总论篇 · 易理篇，40 章）。

- **排盘**：摇卦结果（`7 8 9 6 7 8`）、铜钱正反、或阴阳，直接出本卦/变卦、宫位、世应、纳甲、六亲、六神、旬空、伏神。
- **解析别人排好的盘**：把别的软件输出的盘面粘进去，引擎重新排一遍，再与原文**逐项对账**，抓出"干支阴阳不配""世应错位""六亲与纳甲矛盾"这类错误，把冲突点摆出来，而不是硬着头皮解。
- **判定引擎**：`judge.py` 做两件事——按六步次序取用神（世应优先 → 有动取动 → 有异取异 → 唯一 → 日月 → 伏神），以及按层面隔离出吉凶结论与应期候选。输出带断言表，每条标 `[id][层面]` 与原文出处。
- **应期**：24 条公式 + 四档日月转换（短事按日 / 常事按月 / 久远按年 / 日内按时辰），区分 25 项层面差异。

### `bazi/` — 八字（陆致极体系）

依据陆致极《八字命理学》基础、进阶、动态教程三本。

- **排盘**：公历或农历，自动查城市经度做**真太阳时**校正，处理早子时 / 晚子时两种流派；输出四柱、藏干、十神、纳音、星运、自坐、神煞、旬空、五行分布、大运与起运时间。
- **对账**（最高频也最值钱）：把别人软件的盘粘进来，抠出四柱与大运 → 引擎重算 → 逐项比对。能抓五鼠遁不配套、大运错位一格、十神或藏干错误、大运顺逆反了、起运岁数偏了。
- **解盘**：六视角分工与冲突排序，`07-断事纪律.md` 里的"先问后断""禁用模糊词""三分标注（已确认 / 先前推断 / 本次补推）"。

## 安装

技能就是「一份 `SKILL.md` + 一组脚本 + 参考资料」，装进你的 agent 读取技能的目录即可。

```bash
git clone https://github.com/Changlan4/mingli-skills.git
pip install -r mingli-skills/requirements.txt
```

然后把两个目录放到对应位置：

| 工具 | 技能目录 |
|---|---|
| Claude Code | `~/.claude/skills/` |
| ZCode / DSH 等支持 Agent Skills 的工具 | `~/.agents/skills/` |
| 其他 | 你的 agent 约定的 skills 目录 |

```bash
mkdir -p ~/.claude/skills
cp -r mingli-skills/liuyao mingli-skills/bazi ~/.claude/skills/
```

技能目录名可以改，但 `SKILL.md` 的 `name` 字段和脚本内的相对路径引用要保持一致。

依赖只有两个：

- [`lunar-python`](https://pypi.org/project/lunar-python/) — 农历、干支、节气
- [`sxtwl`](https://pypi.org/project/sxtwl/) — 寿星天文历，八字用

`run.sh` 会自动挑一个装了这两个包的 Python 解释器；也可用环境变量 `LIUYAO_PY` / `BAZI_PY` 指定。

## 快速上手

### 六爻：摇一卦

```bash
export SKILL_DIR=~/.claude/skills/liuyao
bash "$SKILL_DIR/scripts/run.sh" liuyao \
  --yao "7 8 9 6 7 8" --datetime "2025-11-01 10:30" \
  --question "这个项目要不要接" --text
```

```
─────────────────────────────────────────────

```

纳甲、世应、六亲、六神、旬空、伏神、动变与回头克，全部由脚本算出。不加 `--text` 则输出 JSON，方便程序消费。

再跑判定引擎，拿带层面与出处的断言表：

```bash
bash "$SKILL_DIR/scripts/run.sh" judge --yao "7 8 9 6 7 8" \
  --datetime "2025-11-01 10:30" --question "这个项目要不要接" --span "两个月内" --text
```

**注意 `--span`。** 它决定应期按日、按月还是按年扫——问"这个月能不能拿到"和"今年能不能拿到"，结论粒度完全不同。引擎在缺线索时会标注「推断，须复核」。

### 对账（两个技能都有）

```bash
# 八字：可以把生日一起给，逐项核对
bash "$SKILL_DIR/scripts/run.sh" check 盘面.txt --birth "1990-06-15 10:00" --city 上海

# 六爻：给出盘面，引擎重排一遍再对
bash "$SKILL_DIR/scripts/run.sh" parse 盘面.txt
```

全绿 → 放心解。出现 ✗ → 盘与引擎自相矛盾（抄错、软件口径不同、或真排错），必须先把冲突点摆给用户确认，不许挑一个自己信的开解。

## 边界

- **仅供娱乐与文化研究。** 命理无法被科学验证，本项目不承诺预测效力，也不建议把它当作决策依据。请相信科学，理性看待。

- **不替你做重大决定。** 婚姻、疾病、投资、诉讼，只谈倾向与压力点，以专业意见为准。
