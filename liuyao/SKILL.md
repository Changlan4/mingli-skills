# 命理六爻

## 三条铁律

1. **排盘一律由脚本完成，禁止心算。** 干支、纳甲、世应、六亲、六神、旬空、伏神，任何一项靠模型"估"都会错。
2. **断卦必须分两个层面，不许混用。** 吉凶判断层面与应期细节层面，同一个理论在两层的结论可以相反。这条是本技能的最高纪律，详见下文。
3. **规则以原书为准，不凭记忆。** 本技能依据朱辰彬《古筮真诠》（总论篇 · 易理篇，40 章）。
   原书正文**不在本仓库内**，需你自备电子文本（AI 读不了纸质书），按章拆进 `references/` 后才能检索。`references/00-章节索引.md` 是主题 → 章节的定位表：
   凡下判断，先查索引找到章号，再回原书核对。不要用网络通说或记忆里的"六爻常识"替代本书体系。


若报缺 `lunar-python`，先 `pip install lunar-python`。

## 第一步：分清输入

| 用户给的是 | 走哪条 |
|---|---|
| 摇卦结果（数字 / 铜钱正反 / 阴阳） | `run.sh liuyao` 排盘 |
| **已经排好的盘**（粘贴文本，别的软件输出） | `run.sh parse` 解析，**不要自己读爻** |
| 盘面截图 | 先请用户把文字贴出来，或只贴六爻阴阳与月建日辰；图像识别不可靠，不要猜 |
| 只说"帮我看看" | 先问清问什么事（六爻要先定用神）+ 起卦时间 + 摇卦结果 |
| 要问八字 / 四柱 / 批命 | **本技能只管六爻**，明确告知不支持，不要用六爻的方法硬套 |

### 用户给现成盘面时（最高频场景）

**永远不要直接用眼睛读用户贴的盘去断。** 择一：

```bash
# 有起卦时间或四柱，能还原六爻骨架的：
bash "$SKILL_DIR/scripts/run.sh" parse 盘面.txt

# 直接把盘面内容传进去（stdin）
cat 盘面.txt | bash "$SKILL_DIR/scripts/run.sh" parse -
```

解析器做的是：抠出**六爻阴阳与动不动**这个骨架 → 重新排一遍 → 拿重排结果与原文的纳甲、六亲、卦名**逐项对账**。

- **对账全绿** → 放心用标准盘。
- **出现"警告"** → 说明用户原盘与骨架自相矛盾（写错爻、抄错地支、软件口径不同）。**必须把冲突点摆给用户确认**，不许挑一个自己信的开断。
- **出现"缺失"** → 缺日柱/月柱或六爻骨架，按提示向用户补问，不要猜。

若用户只给了卦名 + 动爻，也能用：`judge.py` 可据卦名表反推。

## 第二步：跑判定引擎

```bash
bash "$SKILL_DIR/scripts/run.sh" judge --parsed 盘面.txt --question "问这个月财运" --span "一个月内" --text
# 或
bash "$SKILL_DIR/scripts/run.sh" judge --yao "7 8 9 6 7 8" --datetime "2025-11-01 10:30" \
  --question "..." --gender male --span "两个月内" --text
```

`--span` 传事件的大致跨度（如"一周内""两个月内""今年内""几年"），引擎据此判
短事/常事/久远之占，直接决定应期按日、按月还是按年扫。

**用户没说跨度时，先问一句再跑，不要替他假设。** 档位一错，整条应期线全偏：问"这个月能不能拿到"属短事（按日扫），问"今年能不能拿到"属常事（按月扫），结论的粒度完全不同。真不方便问，才退回默认按月，并在回答里写明这是假设。

引擎输出两张视图 + 一张断言表：

- **层面一·吉凶判断层面**：只含日月 + 主卦 + 动爻变爻。伏神、六神、静爻的变卦**不在这一层**。
- **层面二·应期细节层面**：全量，含六神、伏神、全变卦。
- **断言表**：每条带 `[id][层面]`、结论、依据、原文出处。

**断言表是吉凶主线，先看它再动笔。** 表里通常会给出：用神是否伏藏/空/破/入墓/回头克、世爻是否受伤、世用生克方向，以及 `sr-00 用藏世伤` 这种直接判败的定式。这些条目本身就是结论骨架，你在此基础上组织语言、补细节即可。

**表里没有的结论，先查 `references/00-章节索引.md` 定位章号、回原书核对；核不到就不许说。** 如果表确实太薄、覆盖不到当前情形，如实说明"此处依第 N 章立论（原书请自行核对）"，不要把推断伪装成引擎给的断言。

## 第三步：按七步断卦（书中第八章）

每一步都要产出可核对的内容，不许跳步。

### 1. 实证对轨
从卦里读出**过去与现状**的信息，与用户所述对证：
- 世爻状态（旺衰、空破、动静）→ 求测者当前处境
- 应爻状态 → 对方或环境
- 动爻所指 → 事情眼下在动什么
- 卦体（六冲主快主散、六合主缓主聚）→ 事态节奏

任务是把"卦象显示的现状"讲给用户确认，**不是先讲结论**。对不上就说明这个卦可能不符事实（问非所问、意念不专），应提示用户。
心态卦与问非所问的识别见第 12 章、第 20 章。

**对轨只说卦面能对应的事实，不替用户陈述心理。** 说"世爻入日墓、动而泄气，主眼下提不起劲"可以；说"你心里其实也在犹豫""你还没想清楚"就越界了——用户没讲过的事，不许当成对轨结论抛回去。判断句和事实句要分开写。

### 2. 明确用神

排盘/解析时引擎已按第 11 章的次序给出取用结果与理由链，先看它，再看是否需要人工修正。

**必须讲清走的是第几顺序。** 书里是**六步**，不是三步：

1. **世应优先** —— 现于世位或应位直接取；世应与动爻同现时，世应优先，不论动静
2. **有动取动** —— 动爻、暗动、变爻
3. **有异取异** —— 临月建/临日建/临月合/临日合/临月破/被日冲/旬空被墓的本卦静爻
4. **唯一用神** —— 卦中只有一个，别无选择
5. **日月取用** —— 主卦不见但日令月令上有该六亲，取日月之爻，**不要再去套伏神**
6. **套算伏神** —— 最后手段

引擎输出里的"取用次第"字段会直接告诉你落在第几步，照抄即可，不要把它说成"三级次序"。

**最容易错的一条：「舍衰取旺」是错的。** 书里明确批评这是古法缺陷——取用阶段不准以旺衰取舍，只准以「是否见异」取舍。**破爻、空爻、墓爻恰恰可以、且应当优先取为用神**；取到之后再照常判它衰凶，那是吉凶层面的事。

取用神错的典型：把「这生意成不成」当成求财、世用合一该失效时没失效、多现时按旺衰取舍。详见 `references/liuyao-yongshen.md`。

### 3. 吉凶定性

**先扫结构，再论旺衰 —— 但别把结构当结论。** 书里明确：卦出六冲卦、六合卦或卦变六冲六合，**大多不是吉凶预兆的核心信息**，多用于对证现状与细节；真正左右祸福的，是**世爻与用神的五行生克动变**（第 31 章）。

只有下面几类结构有一票定性的分量，出现时必须在结论开头点出：
- **六冲变六合 / 六合变六冲**（异向互化）—— 带明显祸福预兆，但须"就事论事对应现状"
- **全动化绊（真绊）**—— 动爻尽被绑死，事多不了了之，且了无应期
- 三合局成局、反吟等定式

旺衰的四个影响因素与动变组合见第 13、15、16 章；动卦吉凶卦局见第 21 章；静卦见第 23 章；用神与世爻的相互作用见第 18 章。

### 4. 应期推测

引擎已按第 40 章算出适用公式与候选时点，但要先复核两件事：

1. **档位判对没有**。一个月内＝短事（按日）、一年内＝常事（按月）、一年以上＝久远（按年）、超短期日内之测（按时辰）。引擎缺时间线索时会默认按月并标注「推断，须复核」，你要结合事理常识确认——怀胎十月就是十月，不能只看卦理。
2. **候选要收口**。按六条原则筛：吉断吉应凶断凶应 → 应动不应静 → 应众不应寡 → 应早不应迟 → 应邻不应单 → 盯面不盯点。**输出 2~3 个相连的应期区间，不要只报一个精确的点。**

原盘缺公历起卦时间时，只能给「逢某支」的期，不许编具体年份。细则见 `references/liuyao-yingqi.md`。

### 5. 细节铺开
在吉凶与应期之后做，用于展开过程、现状、相关人事。细节层面可用的理论比吉凶层面宽得多。**但细节结论绝不许倒推吉凶。**

### 6. 事外解读（兼象）
只在卦象发出明确信号时才讲（如"问小事而报大凶"）。不主动一卦多断，不喧宾夺主。

### 7. 趋吉避凶
只讲卦面可调整的方向（时机、方位、行事节奏、人事取舍）。不承诺改变结果，不做玄虚承诺。

## 两个层面：必须分清（书中第九章）

| 维度 | 吉凶判断层面 | 应期细节层面 |
|---|---|---|
| 目的 | 断吉凶成败方向 | 断时间、现状、过程、细节 |
| 完整卦象 | 日月 + 主卦 + 变卦（**只显示动爻**）；伏神不算卦象；不标六神星煞 | 全量：不论动静都显示变卦、伏神全标、三柱齐全、六神星煞详列 |
| 特征 | 严谨细致、泾渭分明（真假空墓、真进假退） | 灵活飘逸、限制放宽（允许月墓月绊、可补缺成三合、空墓绊无真假、三刑相害半合可用） |
| 分析核心 | 用神与世爻的旺衰 | 动爻及用事爻的特殊性（找茬，不用较真） |
| 日月 | 静态（时点分析），成卦那一刻定格 | 动态，随时日推移转换 |

**同一个理论在两层结论不同，这是最容易出错的地方。** 已确认的差异：

| 情形 | 吉凶层面 | 应期细节层面 |
|---|---|---|
| 动爻被日令冲散 | 动不为真破，照常生克 | 仍算日破，须待补破之期才起作用 |
| 月墓 | **没有月墓** | 有月墓，冲墓为期 |
| 日令合动爻 | 是"绊" | 不是绊，是使该爻兴旺，为逢合应事之期 |
| 旬空 | 分真空假空 | 一律看作空，假空者待出空 |
| 三合局 | 成局条件严格 | 可补缺成局 |
| 化进化退 | 有真假进退之分 | 短占无进退 |

写结论时必须声明层面。禁止把应期层面的判断（如"这个爻破了要等补破"）当作吉凶结论，也禁止用吉凶层面的"动不为破"去抹掉应期上的障碍。

1. **先查索引，再回原书核对**，一次只翻命中的那一两章（单章 1~3 万字，别整本通读）。

```
## 卦盘
（parse 或 liuyao 的标准盘，代码块）

## 一、对轨：卦象显示的现状

## 二、用神

过程、相关人事、事外信号

## 六、建议
基于卦面的可行方向，不承诺改命
```

## 红线

1. **不许心算排盘**，不许用眼睛直接读用户贴的盘去断 —— 走 `parse`。
2. **不许跨层面套理论**。吉凶结论只出现在吉凶层面，应期结论只出现在应期层面。
3. **不许把字段当判词**。`is_day_chong` 只说明"日辰冲它"，性质看 `day_chong_judge` 且要看层面。
4. **不许取错用神还给结论**。取用理由要先讲清。
5. **不许跳过结构直接算旺衰**。六冲六合互化、真绊这类一票定性的定式，要在结论开头点出。
6. **不许编造卦辞爻辞**。脚本与原文没给的《周易》原文，明说未载。
7. **不许把书里没有的理论搬来用**。它是朱辰彬体系，不是杂糅派。
8. **不下一口咬定**。用"从卦象看""倾向于""主要依据是"，不用"必然""注定"。
9. **一事一占**。多事混杂时请用户聚焦，或按主次逐条，不要混断。
10. 疾病、法律、重大投资：只讲盘面倾向，提示以专业意见为准。情绪低落或问生死时，语气收敛。
11. **本技能仅供娱乐、文化研究与技术演示，不构成任何专业建议。** 命理无法被科学验证，
    不要暗示结论有预测效力；用户若当真的依据做决定，明确提示"请相信科学，理性看待"。
