# 六爻应期判定规范（spec-yingqi）

> 依据：朱辰彬《古筮真诠》第四十章《应期理论公式归纳》上下篇全文，并交叉核对第9章、第26章下、第27章下、第28章下、第35章、第36章、第10章、第30章。
> 定位：供 Python 判定引擎实现「应期（事件发生时间）推断」使用。
> `chNN` 是原书章节代号（`ch40-1` 表示第 40 章上篇）：本仓库不附原书正文，需自备电子文本（AI 读不了纸书）核对。

## 0. 口径校正（实现前必读）

1. **公式实为 24 条**（ch40-1 编号 1–24，第 24 条为「非主流应期」）。原文自称「常用的应期理论公式大约有二十种左右」（ch40-1:145）是约数，按 24 条实现。
2. **ch40-2 自称「以下五点」，正文实列 6 条编号原则**：①吉断吉应凶断凶应 ②盯面不盯点 ③应众不应寡 ④应早不应迟 ⑤应邻不应单 ⑥应动不应静。原文自述与实列不符，实现按 6 条。漏掉第 6 条会丢掉权重最高的一条规则（「70% 的事实应期产生在动变信息中」）。
3. **「日月转换」在两章中术语不统一**，必须先经第 0.1 节映射，否则档位错位。
4. **吉凶层面与应期层面不是「程度差异」而是「真值差异」**：同一爻在同一卦中可「吉凶层面不作真破、应期层面仍算破须补」。全部 25 项差异见第六节，引擎必须分别求值、分别缓存。

## 一、长短事判定标准与日月转换

### 1.1 判定阈值（原文唯一给出数值的一处）

ch09:367【原文】：「**时间跨度在一个月内的事称为短事；时间跨度在一年内的事称为常事；时间跨度在一年以上的事称为长事。**」

- 这三档有明确阈值。
- `INTRA_DAY`（日内之测）**原文没有给阈值**，只称「超短期」（ch40-1:79）。→ 见第八节待定项 T1。

### 1.2 判定表（可直接翻译为 if/else）【转写】

```
# 输入 span：事件预估跨度，由「事理常识 + 占问意图」判定（原文要求人工判，非机械）
# 原文依据：ch40-2:463-479「你不能脱离事态客观去看卦理，怀胎十月这是常识」

if span <= 1 day:            # 日内之测 / 超短期
    CASE_KIND = INTRA_DAY ; BASE_UNIT = HOUR
    扫描：月 冻结、日 冻结、时 递进（起卦时 → +1时辰 → +2时辰 …）
elif span <= 1 month:        # 短事
    CASE_KIND = SHORT ; BASE_UNIT = DAY
    扫描：月 冻结、日 递进（起卦日 → +1日 → +2日 …）
elif span <= 1 year:         # 常事（ch40-1 称「长事」）
    CASE_KIND = MEDIUM ; BASE_UNIT = MONTH
    扫描：日 冻结、月 递进（起卦月 → +1月 → +2月 …）
else:                        # 长事（ch09）/ 久远之占（ch40-1）
    CASE_KIND = LONG ; BASE_UNIT = YEAR
    扫描：月、日 全冻结、年 递进（起卦年 → +1年 → +2年 …）
```

### 1.3 原文给出的扫描序列实例

设起卦干支为「子年 寅月 辰日」（ch40-1:79 原例）：

| 档位 | 原文扫描序列 | 冻结对象 |
|---|---|---|
| `SHORT`（短事） | 寅月辰日、寅月巳日、寅月午日…… | 月令 |
| `MEDIUM`（常事/ch40 的「长事」） | 寅月辰日、卯月辰日、辰月辰日…… | 日令 |
| `LONG`（长事/ch40 的「久远之占」） | 子年寅月辰日、丑年寅月辰日、寅年寅月辰日…… | 月令 + 日令 |
| `INTRA_DAY`（日内之测） | 寅月辰日申时、寅月辰日酉时、寅月辰日戌时…… | 月令 + 日令 |

【原文】ch40-1:79：「若问以日作为应期计算主体的短事，应期分析层面的日月将转换如下：寅月辰日、寅月巳日、寅月午日……。若问以月份为应期计算主体的长事……寅月辰日、卯月辰日、辰月辰日……。若是跨越多年的久远预测，多以年份作为应期的计算主体……子年寅月辰日、丑年寅月辰日、寅年寅月辰日……。同理，若问的超短期的日内之测，则转换如下：寅月辰日申时、寅月辰日酉时、寅月辰日戌时……。」

### 1.4 伴随转换的三条时效规则（必须同时实现）

| 规则 | 内容 | 出处 |
|---|---|---|
| **月令管当月** | 应期层面月令的作用时效只在当令之月内：「得月令者，在月内克之不衰；遭月破者，在月内生之不起」，出月即「时过则衰」 | ch40-1:81；ch27-2:535-555 |
| **日令管两边** | 「月令管当月，日令管两边」——日令作用时效「短则管当日这端、长则管月外那段」 | ch40-1:81 |
| **常事月外／短事日内** | 「问常事应在月外，问短事应在日内」；「月建管月内的中间那一段，日令却只能管日内与月外的头尾两截」 | ch27-2:557-559 |

**「日辰四时俱旺」的正确解释（只适用应期层面）**：因常事/长事「月转日不转」，日令恒为起卦之日，故曰四时俱旺；但应期层面「日月不同功同权」，**值月之爻的力量恒大于值日之爻**（ch27-2:1005）。

### 1.5 判定基准不是「时间」而是「应期计算主体」【原文】

ch40-1:79 原文用的是「若问以日作为应期计算主体的短事」「若问以月份为应期计算主体的长事」「多以年份作为应期的计算主体」。即：**主应期单位本身即可作为档位判据**，与 1.1 的时间跨度阈值互为表里。

**实现建议【转写】**：优先取「事理常识判定的跨度」与「占问者所问的时间粒度」两项，取较粗者（更保守），冲突时进入第八节 T2 抛 `UNRESOLVED`。

## 二、应期公式全表（1～24）

### 2.0 基础函数与枚举定义【转写】

**地支计算方式枚举（`TAKE_MODE`）**

| 枚举 | 含义 | 计算 |
|---|---|---|
| `VALUE` | 值／填实 | 该爻地支本身逢值之期 |
| `CLASH` | 冲／冲实／冲空 | 六冲对应支 |
| `COMBINE` | 合／补破 | 六合对应支 |
| `TOMB` | 墓 | 该爻五行之墓库支（原文例：木墓未、火墓戌） |
| `TOMB_CLASH` | 冲墓 | 墓库支之六冲 |
| `LONGLIFE` | 长生 | 十二宫长生支（原文例：金长生在巳） |
| `ABSOLUTE` | 绝 | 十二宫绝支（原文例：木绝申、火绝亥） |
| `KIN` | 克 | 克该爻五行之支 |
| `GEN` | 生 | 生该爻五行之支 |
| `EXIT_PERIOD` | 时期出空／出破 | 过了旬空期或破月之后的时段 |
| `SAME_ELEMENT` | 同属性 | 同五行之相邻／相连地支 |
| `MULTI_TOMB` | 多发收藏 | 多现五行之墓库支 |

**单位枚举（`UNIT`）**：`YEAR` / `MONTH` / `DAY` / `HOUR`，由 `BASE_UNIT` 统一指定（见第一节）。

**注意**：原文对绝大多数公式只写「子期／午期」，**不指明单位**；单位一律由 `BASE_UNIT` 决定，不得在公式内硬编码。

### 公式 1｜静爻逢值逢冲

```yaml
id: F01
when: is_static(X) == True          # X 为主事爻（用神/世爻），静而不动
unit: BASE_UNIT
take: [VALUE(X), CLASH(X)]          # 少数情况追加 COMBINE(X)
rank: strength(X) in 旺相 -> CLASH 优先
      strength(X) in 衰弱 -> VALUE 优先（个别 COMBINE 优先）
extend: 应期不绝对局限于主事爻，也可在元神或忌神临值之时应吉凶
applies: 静卦为主；旺衰两类皆可
```

- 【原文】ch40-1:145：「爻静，逢值逢冲之期应事。如主事爻临子水不动，后逢子期或午期应事，这个应期公式多运用于静卦。当然，之中还有个细分的原则，就是主事爻静旺者，多会应在逢冲之期；而主事爻为衰弱者，较多会应在逢值之期（个别应在逢合之期）；而应期也不会绝对性地局限于主事爻，有时候也会在元神或忌神临值之时应吉凶。」
- 实例（ch40-1:169-175，泽天夬占顺风）：子孙酉金静而旺，「应在酉金逢冲的卯日，见到顺风」。

- 实例（ch40-1:179-217，萃之比占妻病）：子孙亥水独发，「等到了亥水逢值逢合之期，即寅日或亥日」，结果应在寅日病好。

### 公式 3｜月破：填实／补破／出月破

```yaml
id: F03
when: is_month_broken(X) == True
unit: BASE_UNIT
take: [VALUE(X),          # 实破：临值
       COMBINE(X),        # 补破：逢合
       EXIT_PERIOD(X, month_mask)]   # 出破：出了破月之后的时段
branch:
  if X in {动爻, 变爻}: 优先"时点出破"（VALUE / COMBINE）
  if is_static(X):      可应"时期出破"（EXIT_PERIOD）
```

- 【原文】ch40-1:219：「爻月破，逢填实、补破或出月破之期应事。如子月占卦主事爻临午火，后逢填实之午期、补破之未期、或出了子月之期应吉凶。」
- 补充【原文】ch26-2:787-793：「应期的运用原则也是『动必有因动为重』，当卦象的动变之爻中出现月破，则多会应在实破或补破等时点出破的时日，若月破之爻只为静爻，则不排除会应在时期出破的时日应事。」
- 三式命名【原文】ch26-2:619-783：「其一，是爻逢破而临值为应期，称为实破……其二是爻逢破而待合为应期，称为补破……其三是爻逢破而出破为应期，称为出破。」
- 实例（ch40-1:221-265，履之兑占兄归期）：用神戌土月破，「六月可望，后至戌月方回，乃应实破之月也」。

### 公式 4｜日冲（日破）：填实／补破／当日次日

```yaml
id: F04
when: is_day_clashed(X) == True     # 应期层面「日冲一律视为破」
unit: BASE_UNIT（短占时落到 DAY / HOUR 层）
take: [VALUE(X),        # 填实
       COMBINE(X)]      # 补破
fast: [TODAY, TOMORROW]  # 最快当日／次日
constraint: 短占且 X 为元神或用神之日破 → 排除 TODAY / TOMORROW
```

- 【原文】ch40-1:267：「日冲者，在应期层面也视为破，一般逢填实、或补破之时应事，当然最快者，也会在当日（期）或次日（期）应事。如寅日占，主事爻临申金，后逢填实之申期，补破之巳期应事。」

- 实例（ch40-1:267-315，风地观占房产）：世爻未土日破，「世爻补破之期在午、未，两月相连」，结果「应在用神填空的卯月套利」。

### 公式 5｜旬空：填实／冲实／出空

```yaml
id: F05
when: is_void(X) == True            # 应期层面「一律看作空亡」
unit: BASE_UNIT
take: [VALUE(X),          # 填空
       CLASH(X),          # 冲空（冲空即实）
```

### 公式 6｜遇合逢冲／遇冲逢合（含三绊解绊）

```yaml
id: F06
when: has_combine(X) == True or has_clash(X) == True
      # 明确：日令、月令、动爻之冲合，在应期层面都算「遇合／遇冲」
unit: BASE_UNIT
take:
  if 遇合: [CLASH(合神A), CLASH(合神B)]      # 两个冲开之期
  if 遇冲: [COMBINE(...)]                    # 两合之时
  always: [VALUE(相绊两元素)]                # 「二不合一」，逢两值之期亦可
untie:                                        # 解绊三路
  1) 冲绊：CLASH(两元素)
  2) 合住两元素之一（等价于「两元素逢值」）
  3) 「并不并因多字眼」：相绊一方再多出一个同类动爻 → 原绊不成立
rank_for_clash_untie:
  吉断 -> 冲绊多避开冲用神、元神的时令（被绊者是忌神时例外）
  凶断 -> 冲绊多应在冲用神、元神之时
exception: 占生产，应期常在冲用神之日（「冲即破也，身不破孩子哪能生得出来」）
```

- 【原文】ch40-1:371-377：「爻遇合，逢两冲之期应事；爻遇冲，逢两合之时应事。包括三绊理论的应期思路，也是遵循这个原则，遇相合逢两冲之期冲绊，例如午动变未为绊，后逢两冲之子、丑期应事；也有逢午、未两值之期应事的，这是根据『二不合一』的特性，总结出来的另一个应期规律。注意在应期分析上，日月动的冲合都可以算是遇合遇冲。」
- 解绊细则【原文】ch36:795-820：「如属吉断，冲绊应期较多会避开冲用神、元神的时令……若被绊的是忌神，则冲绊同时又冲掉忌爻，正好应了吉利之相。同样道理，如属凶断，冲绊多应在冲用神元神之时。」；「如辰土与酉金相绊，适逢合辰土之酉令、或者合酉金之辰令，这绊就算被解开……实际上就是只要到了相绊两元素逢值的时令，就算解绊。」；「并不并因多字眼，意思是说性质相合的两元素皆发动，谓之相并，如果相并的这两个元素其中一方又多出一个，反而就不能算并了。」
- 实例（ch40-1:379-427，剥之观占顺风）：子孙子水被日令合，「爻遇合逢冲应事，所以在冲开所合的午日盼来顺风」。

### 公式 7｜动逢月合：数后三个月内

```yaml
id: F07
when: is_moving(X) == True and has_month_combine(X) == True
unit: MONTH
take: [NEXT_MONTH, NEXT_MONTH+1, NEXT_MONTH+2]   # 起卦月之后三个月
applies: 动爻（生世/克世皆可）
```

- 【原文】ch40-1:429：「动逢月合，一般数后三个月内应事。例如辰月占事，用神酉金发动生世，因为酉金与月令相合，故而巳、午、未三个月内将应吉利。这是我在多年实践过程中的一个重要发现，应验甚广。」
- 补充【原文】ch26-2:363-369：「得月合之爻，其作用范围一般多会在数下三个月之内……例如用事爻得子月合，则数下的丑、寅、卯月内一般可保无虞。」

## 三、多公式冲突时的取舍顺序

> 原文**未以算法形式明示优先级**（无权重、无评分、无严格排序声明）。以下为原文实际陈述过的取舍动作，按执行先后排列：【原文】= 原文直述；【转写】= 为引擎整合的执行序。

### 3.1 执行链

| 阶段 | 动作 | 依据 |
|---|---|---|
| **P0** | 定卦种：应期卦（只问何时）／吉凶卦（问成败）／心态卦 | 【原文】ch10:193：「应期卦：专门反映事件应期的卦种，这种卦**没有吉凶定性层面，只有应期细节层面**。」 |
| **P1** | 先定吉凶，再定应期 | 【原文】ch40-2:3：「**吉断吉应凶断凶应**……吉凶判断的方向决策，决定了应期分析的取舍。即使是同一卦象，如果吉凶方向判断不同，应期的分析方向也将随之摆动，断吉兆要按迎吉神制凶神的思路考虑应期；断凶兆就反过来，应期需按迎凶神制吉神的构思去分析。」 |
| **P2** | 定主应期基数（时/日/月/年） | 【原文】ch40-2:407-411：「断应期，首先要结合事情的实际情况，定好主应期基数……在主应期明确前提下，才接着去推细节应期，做到主次分明。」 |
| **P3** | 取源：应动不应静 | 【原文】ch40-2:345：「吉凶层面的用神却不一定是应期依据的重点，往往动兆对应期分析的作用更为重要，**基本上 70% 的事实应期产生在一卦的动变信息之中**。」 |
| **P4** | 应众不应寡（多现重叠） | 【原文】ch40-2:135-141 |
| **P5** | 应早不应迟（就近） | 【原文】ch40-2:213 |
| **P6** | 应邻不应单（相邻合并成面） | 【原文】ch40-2:281-283 |
| **P7** | 备选过少 → 同属性补充（公式 8） | 【原文】ch40-2:85 |
| **P8** | 事理常识过滤 | 【原文】ch40-2:463-479 |
| **P9** | 加速／迟缓修正 | 【原文】ch40-2:551-605 |

| **P11** | 细节应期深化（可选） | 【原文】ch40-2:487-497 |

### 3.2 关键实例（原文）

- **应众不应寡**（ch40-2:135-141）：「从酉金发动的信息，理论应期应该是辰与酉；从世爻卯木旬空的信息，理论应期应该是卯与酉；那么其中酉金应期是重叠的，这个酉金为实际应期的可能性就相对较大。」

## 四、应期推断五（实为六）原则

> **校验提示**：原文写「以下五点，是易学者应该尽量掌握的应期原则内容」（ch40-2:1），但正文实列 6 条编号。按 6 条实现。

### 原则 1｜吉断吉应凶断凶应（ch40-2:3-83）

应期在吉凶定性前提下展开。断吉按「迎吉神、制凶神」，断凶按「迎凶神、制吉神」。

- 实例 A（讼之睽）：问「文书何时领」→ 寅日冲去忌神申金，得文书；问「文书能否领到」→ 文书无望，凶断应在申金旺相、用神寅木被冲破的申日。
- 实例 B（震之兑问宠物病）：凶断下「仇神申金旺相之时，便是元神断绝祸事呈现之期」，断其难过辰、巳日，实际巳日死。

### 原则 2｜盯面不盯点（ch40-2:85-133）

事前不可能稳定精确到某日某时，应把应期锁定在「面」：理论应期过多时按「多现、就近、相邻」筛选；过少时用同属性补充。

- 实例（丰之夬）：旬空理论应丑月、动兆理论应亥月／寅月，直接锁定「丑寅两月」，结果丑月判刑。

### 原则 3｜应众不应寡（ch40-2:135-211）

多角度推出的理论应期若有重复，重叠者概率更大。

- 实例（革之既济）：六条凶期路径中巳期重复多次 → 首选取巳，再补相邻辰 → 断「辰巳年」，实际巳年被免官。

### 原则 4｜应早不应迟（ch40-2:213-279）

时间排序越前的理论应期，应验几率越大，与「舍远应近」的卦象显示特征相关。

- 实例（坤之比）：忌神逢值戌月、财绊亥月、财衰辰巳、月生冲申之寅 → 戌月最先到达，断「九、十月」，实际戌月。

### 原则 5｜应邻不应单（ch40-2:281-343）

重点看彼此相邻的应期点。

- 实例（未济之晋）：理论应期辰、巳、未、申 → 分「辰巳」与「未申」两块，取最早到达的辰巳块，实际巳月。

### 原则 6｜应动不应静（ch40-2:345-405）

应期依据重点在动兆，而非吉凶层面的用神；**约 70% 的事实应期产生于动变信息**。

- 实例（夬之大壮）：藏伏用神与飞神本可推巳午／申时，但卦有子孙酉金动化申金，「按照应期信息多藏于动兆之中的原则」，取申酉时应晴，反推午未时下雨。

## 七、书中原话摘录

1. **两层定义**（ch40-1:5）：「我们已经知道，断卦存在吉凶与应期细节两个各自独立的分析层面，两个层面的理论特征迥异，吉凶判断层面的理论特征是『严谨细致、泾渭分明』……但到了应期细节分析层面，其『灵活飘逸』的特征，令这些限制被放宽了许多。」
2. **一句话总纲**（ch40-1:15）：「用一句俗话，归纳应期概念与吉凶定性的区别，那就是『**可以找茬，不用较真**』。」
3. **应期的分析重心**（ch40-1:9-13）：「吉凶判断以用神与世爻的旺衰为分析核心，但应期分析却以动爻、及用事爻的特殊性为剖析重点……分析以动爻为主，或重点在用事爻信息里找茬，找出其中失去平衡的破绽点，据此寻觅应期的信息。」
4. **日月转换总公式**（ch40-1:79）：「『短事日转月不转，长事月转日不转，久远之占日月皆不转只有太岁动』。」
5. **时间跨度阈值**（ch09:367）：「往往时间跨度在一个月内的事称为短事；时间跨度在一年内的事称为常事；时间跨度在一年以上的事称为长事。」
6. **古论由来**（ch40-1:81）：「『月令乃万卜之提纲，掌一月之权司三旬之令；日辰为六爻之主宰，司四时之旺相』，这就是根据『月转日不转』这个应期日月转换原理而产生的总结。」
7. **时效规律**（ch40-1:81）：「『**月令管当月，日令管两边**』。意思是讲在应期细节层面，月令的作用时效在当令之月；而日令的作用时效，短则管当日这端、长则管月外那段。」
8. **日令时段**（ch27-2:557-559）：「日令的作用时段规律是：『**问常事应在月外，问短事应在日内**』……月建管月内的中间那一段，日令却只能管日内与月外的头尾两截。」
9. **空破无真假**（ch40-1:77）：「就好象吉凶层面有暗动日破、真空假空之分，但到了应期分析的时候，一切都应视为空与破的道理一样。」
10. **应众不应寡（实例）**（ch40-1:71）：「两种应期思路都聚合在丑，**应众不应寡**，所以应在丑日痊愈的几率较大。」
11. **总原则**（ch40-2:3）：「『**吉断吉应凶断凶应**』……断吉兆要按迎吉神制凶神的思路考虑应期；断凶兆就反过来，应期需按迎凶神制吉神的构思去分析。」
12. **动变为重**（ch40-2:345）：「基本上 **70% 的事实应期产生在一卦的动变信息之中**。」
13. **主应期基数**（ch40-2:407）：「如日内之占据以时辰为主应期单位，短事之占据日为主应期单位，一般的事情据月为主应期单位，长事之占据年为主应期单位等等。」
14. **定面原则**（ch40-2:85）：「断应期的时候，不要绝对性地盯死在某一点，宁愿把应期范围扩大到面……反复筛选出最有可能发生的两个或三个彼此相连的应期，作为预测答案。」
15. **应早／应邻**（ch40-2:213、ch40-2:283）：「众多的理论应期之中，时间上排序越前的理论应期，成为事实应期几率就越大，这可能与『舍远应近』的卦象显示特征相关。」／「你们应该最重点关注彼此相邻的应期。」
16. **真空无应期**（ch28-2:3）：「属真空的爻，则已经衰败无用，**永远堕入空亡不再有应期了**。」
17. **真绊**（ch36:257）：「世爻或用神被真绊，不是事情悬而不决拖延无期限，就是事与愿违的尴尬预示。」
18. **应期意外**（ch35:251）：「应期之问却出现静卦用神衰败的局面，即触及术数上称为『应期意外』的理论，最终导致了事件竟然没有应期的意外趋势。」
19. **月破应期三式**（ch26-2:619-783）：「其一，是爻逢破而临值为应期，称为实破……其二是爻逢破而待合为应期，称为补破……其三是爻逢破而出破为应期，称为出破。」
20. **多现阈值**（ch40-1:1157-1161）：「基本上在日、月、动、变这四个位置上，同时出现三个或以上的同类五行，则算作多现了，可以按照墓来推断应期。」
21. **非主流应期**（ch40-1:1263）：「按照与主流应期对冲的原则，产生的非主流应期概念……它作为非主流轨迹出现的概率很小，往往在极端的条件中才会见到。」
22. **实理优先**（ch40-2:473-479）：「易理只是解读事物轨迹的通用方法……必须站在事态的客观条件基础上灵活分析。」
