### 书中明示的特殊说明（必须写进引擎）

1. **上司／领导 → 官鬼；公司老板、大股东、靠山 → 父母。** 两者不可混。
2. **子孙为福德之神、制鬼之神。"诸事见之为喜，唯独占仕途功名，寓意不利与辞退。"**
3. **兄弟"见我则欺，见财则夺"**：占财物寓意破财、谋事寓意阻碍、感情寓意竞争、事业寓意受制、仕途寓意被裁。
4. **考试类不看官职**："类似道考、乡试之占不应取官鬼爻为用神，而应取代表考试称谓的父母爻为用神"（ch23）。
5. **开铺／开店无固定用神，随问卦心态定**（ch18）："若全身投入视之如事业，官鬼爻为用神；若只作为其中一门项目视之，父母爻为用神；若明显是为求财而占，妻财爻为用神；不一而足。"
6. **同一事可因身份而换用神**：占父母病药，一卦重在父母爻，另一卦因"子孙持世值日"改取子孙——"卦无不灵，在人通变"（ch12）。

## 二、用神多现的取用决策树

> 原文称此为"**主观取用**"的严格先后顺序（ch11）。先按问事类别定六亲（得到"候选爻集合 U"），再走下面流程。

### 第 0 步（前置闸门）：先判卦种，再取用

```
IF 卦象符合"心态卦"特征（见第四节 A）：
    用神 = {子孙(喜神), 官鬼(忧神)}，两者同取，比较旺衰  → 跳出本流程
ELSE：
    按本章顺序在"候选爻集合 U"中选具体爻
```

原文依据：ch11"不管你问的是什么，成卦之前，断卦者脑子里都应该是一片空白……而是等待成卦后仔细地审视卦象，领悟卦中真正的客观所指"；ch12 心态卦"同时存在两个相互排斥的分析核心"。

### 第 1 步：世应位置优先

> 记 `U` = 按第一节定好六亲后、**在主卦中出现**的全部候选爻（不含变卦静爻）。

```
IF U 中存在位于世位或应位的爻：
    取世/应上的爻为用神                    # 压倒一切动静
    若只有 1 个 → 取之，结束
    若有 ≥2 个（世应都有）→ 按"有动取动"再筛：
        IF 其中有动（动爻/暗动/世位之变爻）→ 取动者
        ELIF 皆静 → 按"有异取异"再筛（见第 3 步）
             IF 仍分不出 → IF 问自身:取世位者 ELSE:取应位者
ELSE：
    进 第 2 步
```

原文：**"用神多现，首先优先取世、应位置上有的用神备选爻为用神；若世应位置上都有的，按有动取动原则再细加筛选。"**
**"若用神于世应位置与动爻位置同现，不管动静，均应优先取世应位置上的爻为用神。"**
**"若世应爻都静而不动，按有异取异原则再细筛选……此占若是问自身之事，应优先取代表自己的世爻为用神；若是问他人之事，则应优先取代表他人的应爻为用。"**

- **1.1 世应优先压倒"有动取动"**：世位静爻 vs 他位动爻，取世位静爻。反例代价见 ch20：官鬼两现，申官五爻发动、酉官静而持世，"须世应位置为首要优先选择，故应取处在世爻位置上的官鬼酉金为用神……若错取动爻申金为用，用旺世兴反却是事成的吉利卦局，**取用阶段一步错，即之后步步皆错**"。
- **1.2 世位的"变爻"也算世位**：ch11 艮之升（丑月辛卯日，占子痘症），世位官鬼寅木动化子孙酉金、应位子孙申金静，"世位与应位都出现了子孙爻，按有动取动原则再细筛选；取世位变爻子孙为用神"。
- **1.3 世应同现且一静一动** → 取动者（第 2 步）。**两皆静** → 取见异者（第 3 步）。
- **1.4 世应同现、皆静、皆无异** → 按"问自身／问他人"分流：
  - 问自身事 → 取世位者
  - 问他人事 → 取应位者
  
  原文："此占若是问自身之事，应优先取代表自己的世爻为用神；若是问他人之事，则应优先取代表他人的应爻为用"（例：既济之革，未月辛酉日占"还有弟否"，世应皆有兄弟爻且皆不动，取应爻子水）。
- **1.5 注意**：世应优先只是"入门捷径"。ch35 明言："那只是带领你快速入门的主观取用捷径，当你对古筮理论有了更深刻理解……思维就应该向客观取用靠拢，根据卦象信息与事态现状轨迹对证，来明确用神。"

### 第 1 步补：世用合一（用神持世）的成立与失效

**取用层**：只要用神爻恰在世位，第 1 步就把它取出来；"世应位置优先"与旺衰、动静全部无关。

**吉凶层（这才是"世用合一"能一句话断吉的地方）——成立需同时满足四个条件：**

| # | 成立条件 | 原文 |
|---|---|---|
| C1 | **静卦**（六爻皆不动） | "自问自事摇得静卦，若得用神持世……" |
| C2 | **自占自事**（不是代占） | "代占性质的卦也不适合以用忌持世判断事之吉凶" |
| C3 | **用神必须是六亲**（不是取世爻、星煞、六神为用） | "非以六亲作为用神的不适合应用" |
| C4 | **有根且不逢破** | 见下 |

满足 C1–C3 即："**不管世用旺衰与否，即属吉兆，无须再顾首其他**"。

**失效（四个开关，任一触发即推翻"持世＝吉"）：**

| # | 失效条件 | 后果 | 原文 |
|---|---|---|---|
| F1 | **代占**（占父母病、占妻子工作、占怀孕等他人事） | 持世不作吉兆依据；改看"用神于日月组合的整体旺衰"，近占再参考暗动之爻 | "因为代占之卦，世爻只代表代占者自己而不是事主，世爻也不是事态的最终承受者" |
| F2 | **无根**：持世之爻的元神不现卦中（**伏爻与日月位置的元神皆不算根**） | 短期暂吉、**长事坐实为凶** | "只可保事态短期内暂时无虞，但却不利于长久，长远坐实为凶兆" |
| F3 | **逢破**：持世之爻遭月破或日破 | **即时生效的凶兆** | "用神持世见逢破者，凶兆却是即时生效" |
| F4 | **非六亲用神**（自占疾病／安危／出行取世爻、马星为用、白虎为用等） | 不适用本判断法 | "即使摇得静卦也不适宜以用忌持世判断吉凶" |

**动卦里的"世用合一"只表示分析焦点合一，不自动等于吉。**（ch16 财爻两现取临世之丑土"世用合一，分析未土旺衰便可定吉凶"；ch17"世用合一，分析此午火旺衰即可知吉凶趋势"——都是**照常用旺衰断**，不是免检通过。）

**反向情形（同一爻、两种身份）**：静卦若持世之爻是**忌神**而非用神，则同一卦面翻为凶兆。原文例："若求文书，本应取父母爻为用神，得静卦忌神妻财未土持世，那是事败之兆。若是求财，得妻财未土持世，却变成用神持世，反是有财之兆，祸与福之间可谓天差地远。" → **判用神之前必须先定准问事类别。**

### 第 2 步：有动取动（动爻／变爻／暗动之爻）

```
IF U 中存在动爻、变爻（动爻所化）、暗动之爻（旺相静爻被日冲）：
    取该（些）爻为用神
    若同一用神既现于主卦动爻、又现于其所化变爻 → 取主卦动爻，舍变爻
    若 U 中多个爻皆在主卦且皆动、且无世应之别、无主变之别 → 众爻皆取为用神
ELSE：
    进 第 3 步
```

原文：**"第二顺序，优先取卦中动爻、变爻、暗动之爻位置上有的备选为用神，称为'有动取动'为用。"**

- **2.1 主卦动爻 > 其变爻**：ch28-2"用神两现皆动，取主卦而舍变爻，选主卦动爻子孙亥水为用神"。
- **2.2 两爻皆动、难分彼此 → 皆取为用**：ch11 山火贲（辰月甲戌日，问分红）"卦中现出亥、子两财爻，两者皆动，难分彼此，只好两财皆为用神。子财动化申金回头生显吉兆，亥财动化回头克显凶兆……怕是财得半又失半之兆"（实应：半派现半配股）。**结论写法：不是二选一，而是吉凶并存、事分两半。**
- **2.3 变卦中的静爻不可为用神**："变卦中的静爻其实在吉凶判断层面是不存在的，所以不能在那选用神"（ch11 第 6 步提醒）。**引擎约束：候选集合必须排除"变卦静爻"。**

### 第 3 步：有异取异（静爻中的"异常"优先，不看旺衰）

```
IF U 中存在满足下列任一条件的本卦静爻：
    (a) 临月建   (b) 临日建
    (c) 临月合   (d) 临日合
    (e) 临月破   (f) 被日冲（日破／暗动）
    (g) 旬空被墓
    取该爻为用神
    若只有一爻满足 → 取之
    若多爻满足   → 原文未涉及优先规则（须以事态现状对证）
ELSE：
    进 第 4 步
```

原文：**"第三顺序，选取临月建日建、临月合日合、临月破日冲、或旬空被墓的本卦静爻为用神，称为'有异取异'为用。"**

- **3.1 "舍衰取旺"被明确否定，准确条件是"舍常取异"。**
  - 古法原文（作者引述并批判）："舍休囚而用旺相，舍静爻而用动爻，舍月破而用不破，舍旬空而用不空，舍被伤而用不伤"。
  - 作者的判词："不说其他，单就其明显的据旺衰主观观念为主导的取用原则，已脱离易经的'自然客观成趋势'的基本原理，**缺陷明显**，取用神的目的是为断其旺衰，却已经先在取用阶段就被主观决定了它的旺衰，那还用算吗？"
  - "古论爻出多静，有旺择旺为用神。**我一向反对这种带有主观性质的择用观点**……若在取用阶段就有意识地偏向于选择旺者为用，明显是把主观意念带入到卦的吉凶分析里头。"
  - 取而代之的是野鹤的"取其有异"："舍其不空而用旬空，舍其不破而用月破"。
  - **因此：引擎不得以"旺相"作为多现取舍依据；只能以"是否见异"取舍。**
- **3.2 破爻、空爻、墓爻都可以为用神。** 第 3 步 (e)(g) 直接把它们列为"异"而优先取用。实例：ch11 夬之履（巳月丁亥日，占仆人何日回）"财爻亥水临月破又值日建，明显见异，故舍弃子财而取亥财为用神"。破／空／墓只影响**吉凶层**判衰，不影响**取用层**可否入选。
- **3.3 取到破爻后照常按旺衰断凶**：ch11 风雷益（巳月壬午日，问应聘）"卦中只有一个父母子水，直接取为用神，子水在月令休囚而被日建冲动，爻衰被日冲则被冲破冲散，显出衰相……万难被录取"。

### 第 4 步：唯一用神，直接取

```
IF U 中只有 1 个爻：
    直接取为用神                     # 别无选择
    但标记高风险：假用神概率最高
```

原文：**"第四顺序，取本卦的静爻为用神，即卦中只有一个用神，直接取为用神。这种情况的卦最为常见，因为客观上已是别无选择了。"**
风险提示原文："卦中出现单一的用神，虽然很容易定位，但出现假用神的机会也在相应增加。"

### 第 5 步：日月取用（卦中不见，先看日月，不套伏神）

```
IF U ∩ 主卦 = ∅  AND  (日令或月令的六亲 ∈ 所需六亲)：
    用神 = 日令／月令上该六亲之爻
    STOP —— 不再套算伏神
```

原文：**"第五顺序，卦中用神不见，若日令月令位置上见有，直接取为用神。如申月壬午日卜问有职升否，摇得'风天小畜'……卦中官爻不现，但却有官鬼申金挂于月令之上，即可取之为用神，**不用再去套算伏爻另找用神**。"**
补充（日月为用神的空亡处理）："吉凶层面上，日月是实实在在的怎会有空？……但在应期分析层面，你则可以把它作空看。"

### 第 6 步：套算伏神（最后手段）

```
IF 主卦无、日月无：
    用神 = 本卦所属卦宫首卦（八纯卦）同爻位的该六亲 → 伏于该卦面爻之下
    转入 第三节（伏神专用规则）
```

原文：**"最后，连日令月令上都没有的，最后才通过套算伏爻为用神。"**

### 决策树汇总（可直接翻译为 if/else）

> 下面是为了可读性写的**伪代码**（中文标识符不是可执行的 Python），逐分支复述前面六步。

```python
# U = 候选爻集合（按问事类别定好六亲，且已剔除变卦静爻）
# is_dong(x)  = 动爻 / 暗动 / 动爻所化之变爻
# is_yi(x)    = 临月建|临日建|临月合|临日合|临月破|被日冲|旬空被墓

def pick(U, 问自身: bool):
    # ---- 前置闸门 ----
    if 是心态卦(U):                      # 见第四节 4.2/4.3
        return [子孙, 官鬼]              # 双核心，比旺衰

    # ---- 第1步：世应优先（压倒动静） ----
    in_shi_ying = [x for x in U if x.pos in (世位, 应位)]
    if len(in_shi_ying) == 1:
        return in_shi_ying[0]                       # 直接取
    if len(in_shi_ying) >= 2:
        moving = [x for x in in_shi_ying if is_dong(x)]
        if moving:
            return moving[0] if len(moving) == 1 else moving   # 世应皆现→按有动取动
        # 世应皆静 → 有异取异
        if any(is_yi(x) for x in in_shi_ying):
            return [x for x in in_shi_ying if is_yi(x)]
        # 仍分不出 → 问自身取世、问他人取应
        return 世位爻 if 问自身 else 应位爻

    # ---- 第2步：有动取动 ----
    moving = [x for x in U if is_dong(x)]
    if moving:
        if 主卦动爻 in moving and 其变爻 in moving:
            return 主卦动爻                        # 主卦动爻 > 其变爻
        if len(moving) > 1 and 无法分主次(moving):
            return moving                          # 皆取为用，吉凶并存
        return moving[0]

    # ---- 第3步：有异取异（不看旺衰） ----
    yi = [x for x in U if is_yi(x)]
    if len(yi) == 1: return yi[0]
    if len(yi) > 1:  return 需现状对证(yi)          # 原文未给优先规则

    # ---- 第4步：唯一用神 ----
    if len(U) == 1:
        return U[0]                                # 标记：假用神高风险

    # ---- 第5步：日月取用（不套伏神） ----
    if 日令或月令有该六亲:
        return 日令/月令上该六亲之爻

    # ---- 第6步：伏神 ----
    return 套算伏神()                              # 转第三节

# 硬约束：不得以"旺相"作取舍理由；不得取变卦静爻。
```

## 三、伏神取用规则

### 3.1 何时启用

仅在**主卦无、日月无**之后启用（第 6 步）。且原文对该路径整体持保留态度：

> "事实上在伏爻为用神事占当中，兆凶的比例整体上总是大于兆吉的比例。"
> 野鹤做法："用神旦逢不现，虽有伏神，亦不用之，再占两卦而用神自现。"

### 3.2 怎么套

本卦所属**卦宫首卦**（八纯卦）中该六亲所在的爻位 → 套入本卦同一爻位 → 成为伏神；其上卦面爻即飞神。
原文例：睽（艮宫四世）→ 艮宫首卦艮 → 财爻子水在艮卦五爻 → 套入睽卦五爻，子水成为睽卦伏神。

### 3.3 作者明确**不主张**的旧法（列出但不采用）

古法四关系：飞神克伏神＝"伤身"；伏神克飞神＝"出暴"；伏神生飞神＝"泄气"；飞神生伏神＝"长生"。前三种"是对立的你死我活关系"；"长生"则转为依存的根支关系。
作者的自我否定："首先**推论过程过于繁复**……简单实用才是最高效的理论。"

**→ 引擎不应实现飞伏生克自动推演。**

### 3.4 作者主张的三条路（第 39 章核心）

> **"问事一但见到用神藏伏，不要再去考究那些繁琐的伏飞关系，而应该直接从三个方面的思路去入手分析：一是卦理定性，二是卦意预兆，三是心态反映。"**

**（1）卦理定性**——只看三条易理：

| 判据 | 结论 | 原文 |
|---|---|---|
| 伏神逢旬空、或逢日破／月破 | 事衰败／不成 | "问事只要发现伏神逢空逢破，基本上就是事情衰败的征兆"；"伏居空地，事与心违"；"用神空伏，机会全无" |
| 同上，但**占病** | 伏空反为短期无碍之吉 | "这卦一样是用神伏空，但占病特殊，用神旬空却是短期无碍的信息，所以……依然为吉利的预兆" |
| 同上，但**心态卦特征明显** | 不以藏破断凶 | "卦见用神藏伏又破，除非心态卦特征明显，若按事态卦分析，卦理上即可断之为凶" |
| 用神藏伏 **且** 世爻自变衰败／受动爻克伤（"用藏世伤"） | 直接断事败 | "用藏世伤，直接判断事败即可"；"世爻受制，岂宜自己之谋" |
| 飞神旬空／遭破 | 伏神易出，**仅短期事占有效** | "占病见用神藏伏，无论伏神或飞神旬空，均是短期无碍的吉利预兆"；但"这个理论的效用并不具有通用性，往往只在短期事占中显出其准确率，如占短期病患、短期财运、失物寻找、文书往来等等短期性的事件" |

两条**硬约束**：
- **伏神只与本位飞神发生关系，不与其他动爻论生克。**"伏神只是伏于飞神下面的爻，如同树木的根与表，卦理上它只能与本位的飞神发生关系，而不会与其他动静爻直接作用。"
- **占病可破"伏空必凶"之例**：伏神空在占病场合转为吉兆（见上表第 2 行）。

**（2）卦意预兆**——原文限定为两种方法："涉及到伏神应用的卦意分析法，主要有**藏爻确认法**，与**冲合预兆法**两种。"
- **藏爻确认法**："通过藏伏用神之爻与世爻、应爻、动变的类比，来预兆事态趋势的一种卦意分析法"。例：风火家人（巳月丁未日，问能否在此单位找到工作）——用神官鬼酉金藏于与应爻巳火相冲的父母亥水之下，卦意为"工作将在另外的单位得到，而不会在所问的这个单位获职"。
- **冲合预兆法**：**须同时满足**"用神藏伏"+"与用神相冲／相合者在卦中动变"两大条件，"这种卦意法使用条件苛刻"，"在实断中并不多见"。例：问母亲在外来否——父母卯木藏伏，与用神相冲的酉金发动回头生显旺，"相冲者发动旺相，寓意事态将向相反方向发展"。
- **（补充，抽象一类）用神不在"大环境"**："把应用在吉凶层面的卦象视为一个大环境，若用神不在这个大环境中，则是[此事不在此局]"，"多见于名利谋事之占"。

**（3）心态反映**——事态用神藏伏 + 心态用神（子孙／官鬼）显于世应 → 卦已转为暗心态卦（见第四节）。

### 3.5 应期（与取用分开）

- 总则**"冲飞露伏"**：冲去飞神兼扶旺伏神之时应事。
- 补充**"露伏"**：伏神逢值、逢合之旺相时可取为理论应期。

### 3.6 概念区分（不可混用）

| 概念 | 定义 | 用途 |
|---|---|---|
| **伏神** | 被取为用神的伏爻 | 吉凶定性 |
| **伏爻** | 套入但不作用神的伏爻 | 不作核心 |
| **藏爻** | 整个纯卦套入所得的全部藏爻 | 细节／替身法 |

### 3.7 ch25 补充的"用神替身法"（卦意取用，使用面窄）

- 触发条件：用神寄生于飞爻（伏神）或动爻所化变爻，且**与世爻／动爻拉不上关系**。
- 操作：**"以根替支"**——以用神所寄生的飞爻或动爻替作用神，再与世爻论生克。
- 限定：**"卦意分析法须于不存在卦理分析前提下方可以正确使用"**；"其使用面则变得非常窄小"；"出现的机会其实不是太多，其独立性也不强，多是作为辅助信息或变通思考之用"。

## 四、心态卦与问非所问的判定

### 4.1 两类用神不可混

| 卦种 | 用神 | 核心数 |
|---|---|---|
| 事卦 | 按问事类别取六亲／世应 | 单一核心 |
| 心态卦 | 子孙＝喜神（放心、如愿）＋官鬼＝忧神（担忧、厌恶） | **两个相互排斥的核心，比旺衰** |

原文："心态卦的用神确定，却同时存在两个相互排斥的分析核心……同时通过卦象中喜忧两用神的旺衰程度对比，来判断卦象的吉凶趋势。"

### 4.2 明心态卦（字面即心态）——判定条件

```
IF 问句本身表达忧患／怀疑／喜厌／犹豫（"很担心…""很害怕…""很怀疑…""该不该…""是否如愿"）：
    → 明心态卦，直接定位子孙／官鬼
```

原文列举类型："挂心忧患之占、主观喜厌之占、真假疑惑之占、犹豫不决之占、患得患失之占"。
**"明心态卦相对于暗心态卦，判断起来容易很多。"**

### 4.3 暗心态卦（字面是事态，卦象是心态）——可编程判定

```
IF (事态用神在吉凶层面藏伏不现（伏爻不算卦象内容）
    OR 事态用神虽在，但事态信息"没突出在重要位置上，甚至没有任何显露")
   AND 子孙爻或官鬼爻出现在世位／应位等显要位置：
       → 改判为暗心态卦，弃事态用神，改取子孙／官鬼
```

原文："问卦人自己表面上是在求问某件事态的吉凶趋势……造成了卦象信息的显示过程中，对比于关注事态的心念，忧患的心念明显占了上风，从而使到显示出来的卦象，**事态的信息没突出在重要位置上，甚至没有任何显露**，反而代表心态的信息却清晰显示的反常现象。"
"造成反映事态卦的用神父母爻消失在卦象中（在吉凶判断层面伏爻并不算是卦象内容的一部分），而专门反映心态的用神子孙爻与官鬼爻，却映在世应的显要位置上，**这一事态卦向心态卦转变的反常信号**。"
"问事而事态用神藏伏不露，但心态用神却清[晰显示]……定义暗心态卦的其中一个常见模式。"

**反向排除（必须写入，防止误判）：**
> "这并不是说卦中的子孙爻或官鬼爻，它们出现在卦中显要位置上，就一定是心态信息的显示，也并非所有暗心态卦中的事卦用神都会隐身不现。"

→ 仅"子孙／官鬼在显要位置"**不足以**判为心态卦；须叠加"事态用神藏伏不现"或"事态信息未占显要位置／自相矛盾"。

### 4.4 心态卦的吉凶判定

| 局面 | 结论 |
|---|---|
| 子孙旺相／子孙持世（静卦、有根无破） | 放心、如愿、无碍 |
| 官鬼旺动、鬼动克世 | 忧患属实、事态不利 |
| 静卦**忌神**持世又遭日破／月破 | 即时凶 |
| 子孙与官鬼旺衰对比 | 定吉凶方向 |

原文例：ch12 泽天夬（亥月辛酉日，子占父病服药）——事卦用神父母巳火藏伏，世位子孙酉金持世，"摇得静卦喜神子孙持世有根无破，吉兆明显"，"灌服此药立愈"。
ch23 火山旅（巳月丁卯日占劾奏）——"按心态卦的思路走，自占自事得静卦喜神子孙辰土持世，吉凶定性上已保放心无碍"。

### 4.5 "问非所问"（假用神）的识别与处理

**定义**（ch11）："假用神是指根据问占者的语言表达，表面上主观定位的用神，但它其实却不是事主真实心念的反应，就是说问占者口中所问与心中所想的不是一回事。"

**三种典型触发：**

| 触发 | 特征 | 处理 |
|---|---|---|
| 口问与心念不符 | 预计用神藏伏不现，另一爻带现状特征并趋合世爻 | 对证现状 → 换用神（ch39 例：问事业前景，实为问两间公司待遇，取动而趋合世爻的应爻酉财） |
| 卦象"就重避轻" | 问工作前景，卦却全显感情信息 | 依卦象改判，并声明"既然卦中没有反映，说明没有大的吉凶之事"（ch20） |
| 关切过度 → 转心态卦 | 见 4.3 | 弃事态用神，取子孙／官鬼 |

**新手的保底策略（ch11 原话）：**"对于初学者而言，首先不管它是真是假，暂且全部当它是真用神定位就是。"

### 4.6 ch25 三种"卦意取用"的启用闸门（补充）

| 方法 | 触发条件 | 原文限定 |
|---|---|---|
| 用神替身法 | 用神在伏爻／变爻，无法与世爻直接论关系 | "出现的机会其实不是太多" |
| 拓扑用神法（类象法） | 六亲取用"卦象模糊、或论点矛盾、或无从入手"，而卦意用神突出在明显位置 | "只有在……条件下，适时采用拓扑用神法才可以做到准确断事"；"千万不可矫枉过正" |
| 世应之风采 | 问非亲非故非上司非下属的他人 → 应爻；问自身病况／安危 → 世爻 | 与传统世应取用一致 |

拓扑用神法的具体类象（书中列举）：火灾水患取火爻／水爻（五行）；出国取临马星之爻、问小女孩用神不见而桃花动取桃花动爻（星煞）；守候信笺取朱雀爻、测地震取青龙／螣蛇动爻（六神）；自问住院取世爻之墓（十二宫）；金属财经＝金爻、水产交通＝水爻、家私＝木爻、地域建筑＝土爻。

**硬约束：**"若一卦当中能以六亲取用就可以直接清晰地反映事态吉凶趋势，拓扑用神法则**不能随意使用**的。"

9. **ch11**："用神财爻子水伏又见空亡，所谓'用神空伏，机会全无'，不管卦面如何变动都属枉然了。"

10. **ch11**（收尾）："方法繁琐理论复杂的知识，即使是正确也非幸事，简单而实效的法门，方能称为精论哲理。"

11. **ch23**："一般情况下，自问自事摇得静卦，若得用神持世，不管世用旺衰与否，即属吉兆，无须再顾首其他。"

12. **ch23**："何为无根？持世之爻的元神不现卦中，此静卦即属无根……（处在伏爻与日月位置的元神皆不算根）。凡得静卦用神持世见无根者，只可保事态短期内暂时无虞，但却不利于长久，长远坐实为凶兆。"

13. **ch23**："何为逢破？持世之爻遭月破或日破即为逢破。用神持世见逢破者，凶兆却是即时生效。"

14. **ch23**："另外代占性质的卦也不适合以用忌持世判断事之吉凶……因为代占之卦，世爻只代表代占者自己而不是事主，世爻也不是事态的最终承受者。"

15. **ch23**："此静卦用忌神持世判断之法，非以六亲作为用神的不适合应用。如占自身安危、或自占疾病、或自占出行等等，取世爻为用神不取六亲为用的……即使摇得静卦也不适宜以用忌持世判断吉凶。"

16. **ch39**："问事一但见到用神藏伏，不要再去考究那些繁琐的伏飞关系，而应该直接从三个方面的思路去入手分析：一是卦理定性，二是卦意预兆，三是心态反映。"

17. **ch39**（引野鹤）："用神旦逢不现，虽有伏神，亦不用之，再占两卦而用神自现。"

18. **ch39**："伏神只是伏于飞神下面的爻，如同树木的根与表，卦理上它只能与本位的飞神发生关系，而不会与其他动静爻直接作用。"

19. **ch12**："心态卦的用神确定，却同时存在两个相互排斥的分析核心，以代表喜欢安乐趋势的子孙爻为'喜神'……以代表厌恶忧患趋势的官鬼爻为'忧神'……同时通过卦象中喜忧两用神的旺衰程度对比，来判断卦象的吉凶趋势。"

20. **ch12**："事态卦向心态卦转变的反常信号"——"反映事态卦的用神父母爻消失在卦象中，而专门反映心态的用神子孙爻与官鬼爻，却映在世应的显要位置上。"

21. **ch12**："这并不是说卦中的子孙爻或官鬼爻，它们出现在卦中显要位置上，就一定是心态信息的显示。"

22. **ch25**："卦意分析法须于不存在卦理分析前提下方可以正确使用。"

23. **ch25**："若一卦当中能以六亲取用就可以直接清晰地反映事态吉凶趋势，拓扑用神法则不能随意使用的，只有在正统六亲取用时卦象模糊、或论点矛盾、或无从入手之时，而卦意用神又突出在明显位置的条件下，适时采用拓扑用神法才可以做到准确断事。"

24. **ch18**："只要观察到用神不旺，就已经不是吉利的兆头，也不用再看世爻如何如何了。"

25. **ch35**："那只是带领你快速入门的主观取用捷径，当你对古筮理论有了更深刻理解，特别是懂得分析事态过去现状轨迹的时候，思维就应该向客观取用靠拢。"

## 六、附：用神取错的典型症状与实例（对应问题 5）

### 6.1 症状清单（可直接做校验器）

1. 断出的结论与"用神旺衰"逻辑自相矛盾（如应期落在扶旺用神之时却断凶）。
2. 为凑活用神而绕道"变卦之静爻""日建""化爻""天干化合"，舍近求远。
3. 卦中出现"两个吉凶相反的用神"，被强行二选一。
4. 事态用神恰好藏伏，而子孙／官鬼端坐世应——仍按事卦断。
5. 用神旺衰需要用"取用阶段的主观偏好"来成立（先选旺者再断吉）。
6. 同一卦象在"问财"与"问文书"之间摇摆，导致持世之爻时而是用神、时而是忌神。
