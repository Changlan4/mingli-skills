# 八字命理（陆致极体系）

## 四条铁律

1. **排盘一律由脚本完成，禁止心算。** 干支、藏干、十神、纳音、空亡、大运、起运、
   神煞，任何一项靠模型"估"都会错。用户贴来现成的盘，也必须用脚本重算对账，
   不许用眼睛读完就开解。
2. **解盘按多视角顺序走，不许跳步。** 强弱 → 调候 → 格局 → 刑冲 → 形象 → 动态 → 神煞。
   冲突时「调候为急」。详见 `references/04-多视角整合.md`。
3. **理论依据只认陆致极三本书，结论要能指到页码。** `references/` 下是自整理的规则卡；
   原书正文**不在本仓库内**，需自备《八字命理学基础教程》《进阶教程》《动态分析教程》的电子文本（AI 读不了纸质书），放进 `references/` 才能检索。
   凡是书中没写的断法——具体六亲应期、疾病部位、寿数、发财数目——一律说"书中未及"，
   不许用网络通说或记忆补足。
4. **没问清的前提不许假设，没证伪余地的词不许用。** 学历轴、职业阶段、婚否这些
   "人生时间轴"必须先问用户，不能按"7岁上学、22岁毕业"的通例去套——套错一次，
   后面所有年份就全对错了人。断语里不许出现"消耗感／动荡／不安／压力大"这类
   怎么读都像对的词，必须给能回答"对／不对"的具体形态。详见 `07-断事纪律.md`。

## 第一步：分清输入

| 用户给的是 | 走哪条 |
|---|---|
| 出生年月日时（+性别） | `run.sh pan` 排盘 |
| **已经排好的盘**（粘贴文本） | `run.sh check` 对账，**不要自己读盘** |
| 盘面截图 | 请用户把文字贴出来。图像识别不可靠，不要猜 |
| 只有四柱、没有生日 | 也能对账（查十神/藏干/大运序列/顺逆） |
| 只说"帮我看看" | 先问：年月日时、性别、出生地；或请他把盘贴出来 |

### 排盘

```bash
bash "$SKILL_DIR/scripts/run.sh" pan --date "1990-06-15 10:00" --gender male --city 上海
```

- 城市自动查经度做**真太阳时**；不知道出生地就问，别默认北京
- 农历用 `--lunar`（闰月 `--leap`）；要复现别的软件口径用 `--no-true-solar`
- 晚子时：默认 `sect2`（日柱算当日），「子时换日」流派用 `--school sect1`

### 对账（最高频、也最值钱）

```bash
bash "$SKILL_DIR/scripts/run.sh" check 盘面.txt          # 纯盘面内部一致性
bash "$SKILL_DIR/scripts/run.sh" check 盘面.txt --birth "1990-06-15 10:00" --city 上海
cat 盘面.txt | bash "$SKILL_DIR/scripts/run.sh" check -   # 从 stdin
```

抠四柱与大运 → 引擎重算 → **逐项对账**。能抓：干支阴阳不配、**五鼠遁不配套**、
大运错位一格、十神/藏干/纳音/空亡、大运顺逆、起运岁数。

- **全绿** → 放心解
- **出现 ✗** → 盘与引擎自相矛盾（抄错、口径不同、或真排错）。
  **必须把冲突点摆给用户确认，不许挑一个自己信的开解**——四柱或大运错一个，后面全白搭

## 第二步：解盘（按顺序）

先读 `references/04-多视角整合.md` 与 `07-断事纪律.md`，再按顺序走：

**0. 前提确认**（07）要断具体年份的事，先问清学历轴／职业轴／居所轴／关系轴。
　没问清之前，只讲结构与周期，**不落到"哪年发生了什么"**。用户说记不清的，直接收回，不猜。


**1. 强弱**（01）同方/异方本气与附气、旺相休囚死、得令得地得助。
九档**必须连原始数值一起给**，不许只甩一个"弱"字。有强根者不判极弱（命例丁）。

**2. 调候**（02）调候用神在不在局、寒暖燥湿计分。|总分|>6 时「调候为急」提级。

**3. 格局**（03）取格与依据。注意两种暗毁：**透干被合克**（命例甲）、
**通关把用神之力引走**（命例丁己丑运）。「最强势十神」与「取格」冲突时两种都说。

**4. 刑冲会合**（05）排盘的「刑冲会合」段已自动检出，直接用，别肉眼找。但要分清
**「合」与「合化」**（判错则结论相反）；且记住**合＝牵制失效，不是主动求取**。

**5. 形象**（04）先判**普通格（守平衡）还是特殊形象格（顺其势）**，两者原则相反。

**6. 动态**（05）原局→大运→流年。应期四步：找引动、看程度、定六亲、定时点。

**7. 神煞**：只作事件色彩，**不单独定吉凶**。

**8. 实务**（06，问婚姻/六亲/子女/学业/职业时）：「星与宫」同看。**先用前几条
定星的处境**（透/藏/空/墓/有无根），再算引动——顺序反了就会算出不存在的桃花。

## 引用与边界的纪律

- 每个判断标出**章节标题**，如「（基础教程 第五章 十干和调候）」，不要只写页码——
  不同版本的页码对不上。原文不在仓库里，核对时要回书；若用的是 OCR 版，错字要自行甄别。
- 读者若跑过 `tools/make_pagemap.py` 生成了 `pagemap.json`，可以再附上他那一版的页码。
- 三本书覆盖不到的（合婚、择日、风水、西洋占星、对方长相/职业/籍贯），明说超出范围，不硬凑。
- **胎元、胎息、命宫、身宫只是脚本附带输出，不作判据**（动态 p37 引过批评：
  「命宫一说，浅陋无据」）。
- 命理是**解释框架**不是事实判断：不承诺准确，不替用户做重大决定（婚、病、投资、诉讼），
  健康/法律/投资只谈倾向与压力点。
- **本技能仅供娱乐、文化研究与技术演示，不构成任何专业建议。** 命理无法被科学验证，
  不要暗示结论有预测效力；用户若当真的依据做决定，明确提示"请相信科学，理性看待"。
