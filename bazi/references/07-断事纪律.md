# 断事纪律　怎么断才可信

来源：一次真实用户对话的复盘。那次对方要求"断过去的事来验证是否正确"，
过程中被反复纠正三次，最后才说"这下对了"。**他反馈的核心只有一句：**

> 「我实际体验就是**按常理直接推断**这点最烦人，每个人的人生都不一样，
> 直接按常理推断会有很多错的地方降低可信度。」

以及：

> 「你能不能把**不确定的问清楚了再断事**」

这份卡就是从那次失败里提炼的纪律。**它排在所有技法之前**——技法再准，
用错前提也是全盘皆错。

> 本卡只保留方法，不保留任何具体命例与当事人信息。

---

## 一、铁律一：人生时间轴必须先问，不许假设

那次最大的错误是：**自己假设了一套学历轴（几岁入学、学制几年、哪年高考），
然后拿它去对应具体年份**，导致连着三个年份的事全对错了人。

复盘原话：

> 「更重要的是方法上的错误：**学历轴是我自己假设的，我却拿它去对应具体年份**。
> 这相当于用一个未经验证的前提推导后面全部结论，结论自然站不住。」

### 必须先问清的前提清单

断任何具体年份之前，先确认（有多少问多少，不要嫌烦）：

| 类别 | 要问什么 |
|---|---|
| **学历轴** | 几岁上小学？有没有复读／休学／转学／跳级？哪年高考？大专/本科/研究生？哪年毕业？ |
| **职业轴** | 现在什么状态（在读／工作第几年／待业／备考）？第一份工作哪年？换过行吗？ |
| **居所轴** | 哪年离开老家？在哪读书？哪年去的／回的哪座城市？买房或搬迁是哪年（能到月更好）？ |
| **关系轴** | 谈过没有？大概哪年开始、哪年结束？怎么认识的？ |
| **六亲轴** | 父母是否健在、有无离异或重大变动（仅当用户主动问这块） |

**问不出来的就标"未知"，不要填。** 用户说"记不清"的，直接收回那条判断，不要猜。
那次的处理是对的做法：把记不清的那条明确作废，不再推断。

---

## 二、铁律二：禁用模糊词，必须可证伪

第一次的回答被打回，理由是「**纯粹是套话**」。复盘：

> 「「消耗感」「动荡」「不安」这类词，你怎么读都像对的，等于没说。
> 真正的具体应该到**能回答「对／不对」**的程度。」

### 禁用词清单（命中即改）

```
消耗感、动荡、不安、压力大、起伏、波折、变动、转折、机缘、
不顺利、有阻碍、心思不定、状态不佳、情绪波动、自我怀疑、
容易焦虑、需要调整、会有变化、比较辛苦、有些波折
```

这些词的问题不是"错"，而是**无法被证伪**——用户没法说"不对"。

### 合格的标准：能回答"对/不对"

| ❌ 套话 | ✅ 可证伪 |
|---|---|
| 「这年消耗感明显」 | 「这年有一次持续几周的中断——病、或作息被彻底推翻、或某件事让你停了几周」 |
| 「学业星受制」 | 「不是学不会，是读下去的那条线断了；形态是有人劝你回去，但你没回去」 |
| 「感情有变动」 | 「开始于某年某月，结束于某年某月，形态是异地／见面少／不公开」 |
| 「事业有转折」 | 「这年换了行业方向，不是只换公司」 |

**一条合格的断语，用户读完应该能立刻说"是"或"不是"**，而不是"好像也对"。

## 三、铁律三：「合」是牵制失效，不是主动求取

那次曾从「日主与官星相合」推出"此人想被正统认可"，被当事人直接否定。

修正后的读法：

> 「书里「合」的实际作用是**牵制、让官星失效**……正确读法是：
> **官星自身非常弱，管不了你**，并非「你想要它」。」

**口诀：合 = 绑住／失效，不是 = 想要。**

判断一个星被合之后是什么状态，要数它还剩几分力量：
- 被合住 → 牵制（不自由）
- 被克 → 削弱（管不了事）
- 落空亡 → 虚浮（不得力）

那次官星的处境是**三重削弱**（被合、被克、落空），所以该读成"官星形同虚设"，
而不是"日主渴求名分"。**同样的结构，读成正反两面，结论完全相反。**

## 四、铁律四：先定"星的处境"，再看"引动"

断某类六亲（尤其婚姻）时，最常见的错误是**直接拿一个财星／官星去算流年引动**，
结果全错。因为没先确认那个星自己站在什么位置。

### 正确顺序

```
① 定星：这个六亲用哪个字？（透干的？藏支的？有正用正还是无正用偏？）
② 看星的处境：透干 / 藏支 / 空亡 / 入墓 / 有根 / 无根 / 被合 / 被冲
③ 才去看引动：哪一年把它的处境改变？（合开、冲开、填实、透出）
```

**处境决定"有没有、来不来"，引动决定"哪一年"。** 先不看处境直接算引动，
就会算出根本不存在的桃花。

关键判据（书里的，不是通说）：
- **星坐空亡** → 虚浮不得力（「地支所主的人事，如带空亡，必不得力」）
- **星入墓库** → 藏、晚、少（进阶 p160：「命局中妻星入墓，命主较难得到女人的垂青，故婚姻晚」）
- **合住墓库** → 只是闷着；**冲开墓库** → 才是放出来

**同一个字"藏"与"透"，取象完全不同。** 见不到面、不公开、没有实体接触的关系，
形态就是"藏"，不要硬套成"合"。

## 五、技法一：候选时点不确定 → 用「流月结构密度」区分

当事人记不清事件发生在哪一年时，**不要猜，要逐月算，用结构密度排除**。

### 做法

1. 把候选时点分别算到**流月**（年+月干支）
2. 数每个候选月与原局发生了几个关系（冲、合、刑、害、填实、三合三会）
3. 结构密的那个保留，干净的那个排除
4. 剩下的再用一句追问区分形态

### 为什么有效

一个真正发生事件的月份，盘上通常同时出现多个关系；一个月如果只剩下
全年都存在的背景关系，**说明那个时点不承载事件**。

复盘里的原话是这样排除掉一个候选月的：

> 「这个月除了整年都在的（那个合）之外，流月与原局**几乎没有任何关系**。
> 如果你是（那个时点之后）才不读的，**盘上不会这么安静**。」

**注意**：流月要真算，不能凭感觉。`paipan.py` 能算任意年月，
`relations.py` 能检出该月与原局的关系。

## 六、技法二：三分法标注，避免"按答案编解释"

当事人会怀疑"你是不是照着我说的在圆"。应对办法：

> 「下面分成三类，请按这个区分来看，否则你会觉得我在根据你提供的答案作解释：
> **【已确认】**你告诉我的事实；**【我先前推断】**在你说明之前，我就根据盘面结构推断出来的；
> **【本次补推】**现在新推断的，需要你核对。」

**这个三分法要固定用。** 尤其在用户补充信息之后：
- 之前说出、且用户确认过的 → 【已确认】
- 之前说出、用户还没回应的 → 【先前推断，待核】
- 现在根据新信息补的 → 【本次补推】

另外要有一个 **【收回】** 区，明说哪几条作废了。
那次列了一张"我错的地方（收回）"表，当事人接受度明显更高。

## 七、技法三：主动交代"哪条最没把握"

那次给了星级：

```
★★★ 结构直接推出
★★  加了推断
★   只是参考（风险最大）
```

并主动点出自己最没把握的地方：

> 「哪条错，告诉我错在哪，我会回去查那个字，多半是「合/害/刑落到哪一柱」
> 或「流月和流年谁先发话」这两处之一；**这两处是我目前最没把握的地方**。」

**承认薄弱环节不会降低可信度，反而提高。** 用户要的是判断力，不是神。

---

## 八、边界：三件事坚决不给

**① 对方的身份细节——不给**

对方长相、年龄、职业、籍贯，三本书没有这类断法。
硬凑一套"某天干主白净秀气、某地支主……"是网上通说，不是陆致极的东西，
**而且那正是之前出错的方式**。

**② 未来当确定性——不给**

> 「未来比过去不确定得多。过去只有一种走向，未来有好几种可能，
> 我无法判断哪一扇门会被推开。下面给出的是在结构上更顺或更堵的方向，不是保证。」

**③ 具体钱数、寿数、病名——不给**

## 九、一份合格回答的骨架

```
一、排盘（脚本输出，先确认无误）
二、结构（强弱/调候/格局/刑冲/形象，数值+页码）
三、前提确认 ← 缺这步就是耍流氓
     "在断具体年份前，我需要先知道：①… ②… ③…"
四、已确认的事实（用户说过的）
五、先前推断（说在前面的，待核）
六、本次补推（新的，★标强度）
七、收回（错的，明说作废）
八、边界（不给什么，为什么）
```

**第三步是分水岭。** 跳过它直接进第五、六步，就是那次被打回的原因。
