页码为原书 PDF 页（p62-75）。

## 一、两个阵营：日主同方 vs 日主异方（p64-65）

八字里的五行，按与日主的关系分成两堆：

| 阵营 | 包含 | 十神 | 道理 |
|---|---|---|---|
| **日主同方** | 同我、生我 | 比劫、印 | 跟日主站同一条阵线，是日主一方的力量 |
| **日主异方** | 克我、我克、我生 | 官杀、财、食伤 | 克的、被克的、被泄的，都是消耗"我"的能量 |

**这是全章的地基。** 强弱不是数"金木水火土各几个"，而是数"同方几个、异方几个"。

## 二、图解分析法四步（p65-68）

### 操作-1：只数天干 + 地支本气

**天干每个计 1，地支只取本气计 1。** 此时还没数藏干的中气余气。

### 操作-2：再数地支藏干的中气、余气

每个中气/余气计 1，但**记在括号里**，与操作-1 的本气分开呈现。

书中胡适命造的标注：

```
日主同方：我 + 同我：火 = 2（1）     ← 日主丁火 + 时干丁火 = 2；未中藏丁 = 1
          生我：木 = 1（1）          ← 年支卯木 = 1；未中藏乙 = 1
日主异方：我生：土 = 2（0）          ← 日支丑 + 时支未
          我克：金 = 2（1）          ← 年干辛 + 月干庚；丑中藏辛 = 1
          克我：水 = 1（1）          ← 月支子；丑中藏癸 = 1
```

→ 同方记 **3（2）**，异方记 **5（2）**。（胡适：辛卯 庚子 丁丑 丁未）

### 操作-3：按 月令 标 旺相休囚死

强弱必须在出生时的自然气候环境下考察，所以给每种五行标上状态：

> **当令者旺，令生者相，生令者休，克令者囚，令克者死。**

即：设月支五行（令）为 X
- X 本身 = **旺**
- X 所生 = **相**
- 生 X 者 = **休**
- 克 X 者 = **囚**
- X 所克 = **死**

例：子月（水令）→ 水旺、木相、金休、土囚、火死。

### 操作-4：比较总数，定九档

把同方与异方各自的「本气」与「括号内附气」加总比大小。

| 九档 | 含义 |
|---|---|
| 极强 | |
| 很强 | |
| 强 | |
| 稍强 | |
| 中和 | 同方 ≈ 异方 |
| 稍弱 | |
| 弱 | |
| 很弱 | |
| 极弱 | |

书中两例直接给了答案，可作校准锚点：

| 命例 | 八字 | 同方 | 异方 | 结论 |
|---|---|---|---|---|
| 胡适 | 辛卯 庚子 丁丑 丁未 | 3（2） | 5（2） | 否 | 1/3 | **弱** | 基础 p68 |
| 南怀瑾 | 戊午 乙卯 甲子 乙亥 | 6（1） | 2（1） | 是 | 3/3 | **很强** | 基础 p63 |
| 袁树珊 | 辛巳 丁酉 乙巳 戊寅 | 2（0） | 6（6） | 是（时支寅帝旺） | 1/3 | **弱** | 动态 p22 |
| 文天祥 | 丙申 甲午 丁巳 壬寅 | 7 | 8 | 是（巳帝旺、午禄） | 3/3 | **很强** | 动态 p87 |

### 两个案例各自推翻了什么

**袁树珊推翻"数字小就一定很弱"。** 原书原话：

> 「只有时支寅木（帝旺），可以为日主乙木之根，故命局日主**没有到「很弱」的地步**。」（动态 p22）

同方 2 对异方 12，差 −10，按数字该是极弱；但有一个帝旺之根，判「弱」。
**有强根者，再弱也弱不到从格那一步**（与「从格须无根」的判法一致）。

**文天祥推翻"数字低于对方就是弱"。** 原书原话：

> 「丁火生夏季午月当令，天干有甲木正印、丙火劫财，地支有巳（帝旺）、午（禄），
> 自身显然**很强**。」（动态 p87）

同方 7 对异方 8，差值是 −1，按数字连"强"都勉强；但**得令、得地、得助三项全得**，
判「很强」。

### 由此得出的档位次序

```
得令 + 得地 + 得助 全得  → 很强（数值再难看也不改变）
得其中两项              → 强
只得一项                → 看数值，但若有强根，最差到「弱」
一项都没有              → 弱 / 很弱 / 极弱，按数值
```

**三要素是定性的硬指标，数目是辅助。** 这跟原书附录第 13 步的说法一致：
「以五行计分为主，比较……数量，**同时参考干支刑冲会合**，判定」——
"判定"这个动作本来就是综合的，不是算术。

四个锚点现在由 `tests/test_all.py` 守着，改引擎就会立刻报警。

⚠️ 书中没有给出九档的逐档数值公式——**这不是遗漏，是方法本身如此**。
原书附录「八字结构分析图解流程」（p296-297）第 13 步写得很清楚：

> 「以五行计分为主，比较日主同方与日主异方的数量，同时参考干支刑冲会合，判定日主强弱状态。」

也就是说：**强弱是定性比较 + 参照刑冲会合的综合判断，不是代入公式算出来的。**

`strength.py` 的档位因此做成『数值为主 + 有无强根校正』：三个锚点都能对上，
中间档位仍属推断。**下结论时必须把原始数值一并写出**，
让用户看到依据，而不是只甩一个"弱"字。

## 三、三要素校核：得令、得地、得助（p62）

这是传统说法，书中用南怀瑾命例演示：

```
甲 生 卯 月 → 正是甲木当令的节令 → 得令
时支 亥 → 亥是甲木之长生      → 得地
月干乙、时干乙（比劫），子亥皆水（印）→ 得助
```

**三项全得 → 最强**（书中原话"当令、得地、得助……日主显然可以判断为最强"）。

本技能的实现口径：
- **得令**：日主五行在月令为「旺」或「相」
- **得地**：日主在四地支的十二长生为 长生 / 临官 / 帝旺（**不含**冠带、墓库，只列作"弱根"）
- **得助**：比劫、印星在天干透出或藏于地支，累计 ≥3 处

三要素与图解数值会一起输出，**两者应当互相印证**；若结论打架，先把矛盾摆给用户，不要挑一个自己信的往下推。

## 四、用神：强弱只是提出问题（p68-75）

> 「有了基本的强弱评估……我们发现的问题就是八字结构内部五行处于了不平衡状态。
> 接下来的关键，就在于能否找到解决问题的办法……这个机制，在传统命理学中称为「用神」。」

### 扶抑用神的取法（p69-70）

**「扶」与「助」是两件事，别混：**

| 手段 | 关系 | 十神 |
|---|---|---|
| **扶** | 生我 | 印 |
| **助** | 同我 | 比劫 |

- **日主弱** → 找「扶助」：优先在命局内部找印星或比劫
  - 胡适（弱）：时干丁火与日主同类，可比助日主 → **丁火为用神**
- **日主强** → 找「抑制」或「宣泄（消耗）」：食伤泄秀、财耗、官杀制
  - 南怀瑾（很强）：年支午火（本气丁火）充当宣泄强木的机制，
    把强木的能量转生年干戊土，是最有效的平衡渠道 → **午火为用神**

**用神必须在命局内部找**（命局是内因、是根本），不能凭空从大运里借。

### 用神是否完好（p70-71）

> 《凿篇》：「用神不可损伤，日主最宜健旺。」

判断结构良窳的关键，不只看有没有用神，还要看**用神有没有被破坏**：

- 用神周围没有直接克制它的五行 → 用神完好 → 结构较良
- 用神被冲、克、合去 → 用神受损 → 无法承担平衡作用 → 结构有缺陷

胡适、南怀瑾两造的扶抑用神都完好（周围无直接克制），故为佳构。

### 这只是「扶抑」一路

调候、格局、形象各有自己的用神，**四者可能互相矛盾**。冲突时的处理次序见
《05-多视角整合.md》。千万不要把扶抑用神当成唯一答案。

## 五、常见坑

1. **只数藏干总数，不分阵营。** 数出"金2木2水2火1土3"没有意义，
   必须归到同方/异方。
2. **把"土多金埋"当成"得地"**。土多确实能埋金，但图解法的意思是数目上土在异方
   （对辛金而言土是印，属同方）——注意：印是**同方**。别把"生我太多"误判成异方。
3. **忽略括号内的附气。** 中气余气常常是翻盘的关键（李敖盘里水的附气有 2）。
4. **月令看月支本气，不看节气名。** 辰月是土旺，不要因为"春天"就认为木旺。
5. **档位之外的信号更重要。** 强弱只是六个视角之一，不要拿一个"很弱"就下人生结论。
