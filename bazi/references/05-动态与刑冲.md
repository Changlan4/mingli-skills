# 上半：刑冲会合（基础教程第四章）

## 一、天干相冲（p79）

只有四组，且都是**阳冲阳、阴冲阴**：

| 组 | 说明 |
|---|---|
| 甲 — 庚 | 庚金克甲木 |
| 乙 — 辛 | 辛金克乙木 |
| 丙 — 壬 | 壬水克丙火 |
| 丁 — 癸 | 癸水克丁火 |

书中原话：「相冲也有相刺的含义……阴阳不能配合，故发生冲突。
**因为相刺是无情的表现，相冲一般不以吉。**」

注意：天干还有**五合**（甲己、乙庚、丙辛、丁壬、戊癸）。合与冲是两套机制，
合能牵制、冲能损伤。**合还能解冲**（见下）。

## 二、地支六合（p79）

| 合 | 化 |  | 合 | 化 |
|---|---|---|---|---|
| 子丑 | 合土 |  | 辰酉 | 合金 |
| 寅亥 | 合木 |  | 巳申 | 合水 |
| 卯戌 | 合火 |  | 午未 | 合土 |

**合与合化是两件事。** 合只是关系，能不能"化"要看局中是否存在化的条件
（月令、化神透出、无冲克破坏）。**不要见合就断化**，这是最常见的错误。
详见下一节——这一层比想象的重要得多。

## 二之二、「合」与「合化」是两回事（动态 p31）★

**全书最精微的一层，也是最容易被一笔带过的地方。** 原书专门用袁树珊命造来讲。

### 合化的条件：必须有「引化之神」

> 「合化需要条件，就好像化学反应，需要添加催化剂……引化之神主要在月令，
> 即地支为土，即辰、戌、丑、未月，或为火，即巳、午月等。
> **因为月提是秉令之神，发号司令者也。**」（p35）

- **天干合化**（如甲己合土）：地支要有引化之神——土月或火月
- **地支合化**（如巳酉合金）：天干要有化神——庚或辛
- **没有引化之神 → 「合而不化」**，只是互相牵制，性质不变

### 合与合化，能量差一个量级

原书原话：「两者的「能量」程度是不同的，它们对全局的作用也不一样。」

### 袁树珊的「玄机」（p36）

```
巳酉半合金局，年干辛金看似可引化
但最终判为「合而不化」
```

> 「如果地支巳酉、酉巳合化成功，命局中**七杀与食神的平衡会出现重大的倾倒**：
> 七杀完全占了压倒优势，几乎到了不可制约的状态。
> 所幸……最终是**合而不化**。这样，巳火的火性就不至于完全丧失，
> 它依旧可以成为丁火食神的根基，**保持了食神制杀的基本格调**。」

> 「这是这个结构中的「玄机」。如果不细辨「合」与「合化」，
> 对它们的区别没有清醒的认识……是很难分析到位的。」

**教训**：同一个「巳酉半合」，判成"化"还是"不化"，结论完全相反——
一个是被杀压死，一个是食神制杀。**不能见合就断化。**

### 判合化的清单

1. 有没有引化之神？（干合看月支，支合看天干）
2. 引化之神在月令吗？（月提秉令最有力量）
3. 有没有被冲、被合去破坏？
4. 化神是否透出、有根？

四条缺一条，就往「合而不化」判。

## 三、"合能解冲"（p86，胡适命造）

书中的经典演示，逻辑必须学会：

```
胡适 辛卯 庚子 丁丑 丁未
地支：子丑合、丑未冲、卯未半合木局
```

推理链（原文）：
1. 身弱，扶抑用神是时干丁火
2. 丁火唯一的弱根在未字里
3. 日支与时支丑未相冲 → 未中余气丁火会受伤
4. **但** 丑又与月支子六合，且子丑的位置在丑未冲之前
5. 「子合住了丑，削减了丑去冲未的力量，这就是所谓「合能解冲」」
6. 于是未保住了，又跟年支卯遥合成半个木局，木生火 → 丁火得生
7. 结论：地支的冲合关系**没有损害用神的根基**

**这个推理展示了刑冲会合的正确用法：不是单独说"有冲就不好"，
而是看它落到哪个字上、那个字是不是用神的根。**

## 四、地支六冲与刑害

- **六冲**：子午、丑未、寅申、卯酉、辰戌、巳亥
- **三合局**：申子辰(水)、寅午戌(火)、巳酉丑(金)、亥卯未(木)
- **半合**：三合中任两字（须含中神才有力），如卯未半合木
- **会方**：寅卯辰(东方木)、巳午未(南方火)、申酉戌(西方金)、亥子丑(北方水)
- **相刑**：子卯（无礼之刑）、寅巳申（恃势之刑）、丑戌未（无恩之刑）、辰午酉亥自刑（原书 p82）

## 四之二、巳的两重性——三合局里唯一的异类（动态 p36）★

三合局由「长生、帝旺、墓库」三字组成。首字照例是**帝旺五行之长生**，
而且**它的本气正好生那个五行**：

| 三合局 | 首字 | 首字是谁的长生 | 首字主气 | 主气对成局五行 |
|---|---|---|---|---|
| 亥卯未 木局 | 亥 | 甲木之长生 | 水 | 水生木 ✓ |
| 寅午戌 火局 | 寅 | 丙火之长生 | 木 | 木生火 ✓ |
| 申子辰 水局 | 申 | 壬水之长生 | 金 | 金生水 ✓ |
| **巳酉丑 金局** | **巳** | **庚金之长生** | **火** | **火克金 ✗** |

> 「唯有巳酉丑不同，巳是金（庚）之长生，**主气是火，火是克金的**。」（p36）

所以：

> 「可见巳具有**两重性**，它本身的性质对周围环境有很大的依赖性：
> 当环境火弱时，它见酉合则**归顺金**；当环境火强时，即使见酉金来合，
> 它还是顽强地显现出自己**原来的火性**。」（p36）

**用法**：命局里有巳酉半合时，不能一律当"合化成金"。
要看局中火势——火强则巳仍是火（是制金的），火弱才归顺金。
这正是袁树珊丙午年"两巳夹击酉金"的学理基础。

## 五、刑冲会合的正确用法

**它本身不是结论，是对其他视角的修正器。** 判断顺序：

1. 先用强弱/调候/格局得出结论（比如"用神是丁火，根在未"）
2. 再看刑冲会合落到哪：冲的是不是用神的根？合的是不是把帮手合走了？
3. 若冲克用神之根 → 结构受损（但要看有无"合解"）
4. 若合去忌神 → 反而是好事

❌ 错误：见到"丑未冲"就说"婚姻不顺"。那跟算命摊没区别。

# 下半：动态分析（动态分析教程）

## 六、三个层次，不能只看原局

陆氏动态分析的核心主张：**原局、大运、流年构成三个层次，必须联动看。**

### 先看「运限」：四柱本身就是一条时间轴（动态 p36）

在谈大运之前，四柱本身就已经内嵌了时间分段：

| 柱 | 阶段 | 按每柱 16 年计 |
|---|---|---|
| 年柱 | 幼年、少年 | 1-16 岁 |
| 月柱 | 青年 | 17-32 岁 |
| 日柱 | 中年 | 33-48 岁 |
| 时柱 | 晚年 | 49 岁以后 |

原书称其为「运限」——「八字内部具有的人生过程在时段上的缩影式的段落」。
**用处**：同一个字落在不同柱，它"发话"的人生阶段就不同。
时柱的财与年柱的财，不是一回事。

### 再看大运流年

- **原局**是"命"：固定的结构，决定底盘
- **大运**是"运"：十年一变的背景，**会改变原局的强弱与格局**
- **流年**是"年"：一年一变，是触发点

关键观念：**大运流年不是"在原有吉凶上加减分"，而是会重新配置结构内部的力量关系。**
同一个字，在原局、大运、流年里的作用是不同的。

对应章节：
- 第三章 动态分析模型（p79）
- 第六章 从命局到大运流年（上）（p171）
- 第七章 从命局到大运流年（下）（p213）
- 第八章 从大运流年到命局（p247）

**注意第六、七、八章的标题方向**："从命局到大运流年"与"从大运流年到命局"是
两个相反的推法——一个是看命局会在哪些年份被引动，一个是看某个年份会冲击命局的什么。
**问"什么时候出事"用前者，问"这一年怎么样"用后者。** 这是实务上很好用的分野。

## 七、干支扭曲（第五章 p137-160）

### 是什么

**同一干支在命局与大运流年之间反复叠加**，会产生一种「分裂力」或破坏力，
相关干支的信息都受不利影响。原书称之为「扭曲」，并分**等级**（一级、二级……）。

> 「由此产生了「分裂力」，或者是破坏力。与之相关的干支信息，
> 都会受到严重的不利影响。」（p141）

### 一个容易被忽略的要点：扭曲不只在运岁上

> 「显然，干支扭曲的影响，**不只发生在大运、流年、流月、流日对原局的作用中，
> 而且还存在于命造内部四柱之间。**」（p144）

原书举的例子：某人 17 岁父母离异、随母再未见生父一面，其**八字年月两柱
本就是相同的干支（一级扭曲）**，原书认为这与家庭不幸同源
（「只是「生离」和「死别」的差异」）。

**所以拿到一个盘，先看四柱内部有没有同干支重复**——这是静态的、原局自带的信息，
不必等运岁。

### 与「伏吟」的区别

- **伏吟**（第十章）：干支完全相同地"撞上"，如原局有丙寅、流年又逢丙寅
- **扭曲**（第五章）：同干支（或同五行）的重复叠加造成的结构分裂，范围更宽

两者都提示"引动"，但扭曲更强调**结构性破坏**，伏吟更强调**重复触发**。

⚠ 本章细节（各级扭曲的判定、与具体事件的对应）原书讲得很细，此处只记框架。
下判断前请回查 `references/book03-dongtai/` 第五章原文。

## 八、反吟伏吟（第十章）★

- **反吟**：大运或流年与原局某柱**天克地冲**（干支同时相冲）
- **伏吟**：干支与原局**完全相同**（如原局有丙寅，流年又逢丙寅）

两者都是**引动**的信号，不等于必凶。要看被引动的是用神还是忌神。

### 实战案例：戚继光的己巳运（第八章 p253-254）★

全书最有说服力的一个「反直觉」案例。

**戚继光 戊子 癸亥 己巳 乙亥**，日主己土身弱。走到**己巳运**——
巳火生己土、己土帮身，从一般强弱分析看，**这该是扶身的好运**。

事实相反：己巳运正是他晚年最惨的十年。张居正死后他被调职、夺职罢官、
妻子离异，贫病交加而终（1588 年）。

**为什么？** 原书给出结构上的答案：

```
己巳运 = 与日柱己巳【伏吟】
同时 日柱己巳 与 月柱癸亥 → 天克地冲（癸克己、亥冲巳）= 反吟
同时 日柱己巳 与 时柱乙亥 → 天克地冲（乙克己、亥冲巳）= 反吟
    → 一柱被两重反吟夹击，没有任何缓解途径
    → 而且走己巳运时，运限已正指向时柱（49 岁后 = 晚年）
```

原书原话：「反吟没有任何可以缓解的途径。而且，对日柱己巳来讲，时柱乙亥的冲更凶，
是「（致）入」：乙木（克）己土，亥水冲巳火。而戚继光步入己巳运的时候，
生命的流程已经正指向了时柱，时柱的运限（49（岁）运）是晚年。」

### 由此得出的最高原则（p253）★

陆氏在这里自述了他的**顿悟**：

> 「从一般的强弱分析出发，命局日主弱者，走扶身、强身的运应该是（好的）……
> 此时，我领悟到分析大运、流年的一个重要关键，那就是——
> **不能简单地谈运岁的五行所喜所忌，而必须回到原局结构去，
> 回到原局的每一个可能发生关系的「字」上，作出细致、完整的判断。**
> 当时的感觉，顿觉豁然开朗，好像辛弃疾所写的词句——
> 「众里寻他千百度；蓦然回首，那人却在灯火阑珊处」！」

**这一条要盖过「身弱喜印比」这类公式。** 大运五行再合喜用，
只要它跟原局某个字构成反吟、伏吟、合化、刑冲，结论就可能完全相反。

所以动态分析的正确问法不是「这步运的五行对我好不好」，
而是「**这步运的干支，跟原局哪几个字发生了什么关系**」。

## 九、干支优略等级（第九章 p287-295）★

### 戴氏的快速切入法（p293）

六十甲子分上/中/下三等，**针对日主而言**。用法两条：

1. 依命局五行强弱定出喜忌，提出用神（药神/喜神），确定格局
2. 标出各柱干支的等级

两点结合，判断命造高低会比较明确。原书举的例：

> 郑先生 己卯 戊辰 戊子 甲寅，干支等级（下）（上）（上）（上）
> 「此造日元戊子是上等干支，月时两柱也为上等，只是年柱为下等干支，
> 此造**三上一下，决不是下等命**。」

**但原书也说明：「这是一种快速切入的判断法，但不是绝对可靠的。」**

### 陆氏补上的客观标准（p294）★

戴氏没说清分级依据，陆氏用**五行生克**给出五种基本类型：

| 类型 | 定义 | 例 | 优劣 |
|---|---|---|---|
| **上生下** | 天干五行生地支本气 | 甲午、乙巳 | **优**（相生有情） |
| **下生上** | 地支本气生天干五行 | 甲子、乙亥 | **优**（相生有情） |
| **上克下** | 天干克地支本气 | 甲辰、乙丑 | 中（尊制卑） |
| **下克上** | 地支本气克天干五行 | 甲申、乙酉 | **下等**（卑克尊=冒犯） |
| **上下同** | 干支同五行 | 甲寅、乙卯 | **优**（同类如兄弟，有互助） |

理论依据是沈孝瞻《子平真诠》的两个标准：**有情/无情**、**有力/无力**。

**为什么上克下和下克上不同等？** 原书讲得很讲究：

> 「天干对于地支而言，天干为阳，地支为阴；天干为「尊」，地支为「卑」。
> 因此，「上克下」是「尊」制「卑」；而「下克上」则是「卑」克「尊」，
> 成了一种「冒犯」。因此，类型 (4) 的干支就要放到「下等」层次中去了。」

### 还有一类：上下相合（p294）

> 「比如戊子，戊为阳土，子为癸水（癸为地支子之主气）。戊子正好上下相合，
> 自然是有情的。这样的干支还有**丁亥、辛巳、壬午**等，也是上下相合的状态。」

即：**天干与本柱地支的藏干相合** → 有情 → 上等。

### 引擎已实现

`lib/ganzhi_level.py`，排盘时自动输出逐柱等级。
郑先生一例作为回归测试锚点（下·上·上·上），123 项测试中有它守着。

**实务意义：不要只看"伤官"两个字，要看是哪个伤官。**
同是伤官，坐禄坐刃与坐绝坐墓，天差地别。

## 十、动态分析模型：大运 × 运限（动态 p86）★

陆氏在《动态分析教程》第三章提出的模型，一句话概括：

> 「这个模型的特点是把**大运跟原局的运限**联系起来，因为运限代表了人生的不同阶段，
> 而不同阶段各自有自己的特点。应用这个模型，将与之相对应的大运跟当时的运限干支
> 联系起来，这样可以更清晰地反映和刻画不同阶段的人生的重点信息。」（p86）

也就是说，**不是单看大运，而是看"这一步大运踩在人生的哪一段上"**。
同样一步凶运，落在年柱运限（少年）和落在时柱运限（晚年），应的事完全不同。

### 示范：朱元璋 54 岁丧马皇后（p86）

```
朱元璋 戊辰 壬戌 丁未 丁丑
54 岁，流年壬戌，大运丁卯（46-55）尾
```

推理链：

1. **运限**：54 岁已行进到**时柱**
2. **大运**：丁卯运尾；卯与时支未 → **卯未半合木局**
3. 这一合解除了原局本有的丑未关系
4. **月柱壬戌引动命局原有的丑戌相刑**
5. 相刑的结果：「戌库的墓神**丁火比肩**，去了丑库中的墓神**辛金偏财**」（丁克辛）
6. **丑库是妻宫**，库中辛金偏财正是妻子（此造无正财，以偏财为妻妾）
7. → 马皇后去世

**三个可复用的点**：
- **墓库之刑 = 开库，库中墓神互相攻伐**，不是抽象地"刑主凶"
- **大运的合会可以先解除原局的一组关系，再引爆另一组**（卯未合解了丑未，丑戌刑才凸显）
- **星宫重叠**：丑既是妻宫，库中又藏着妻星辛金——宫与星在同一个字上，一击即中

## 十一、动态分析的操作示范：袁树珊三案（动态 p33-36）★

这是全书**唯一给出完整推理链**的地方。三个案例分别演示了丧亲、得子、婚育，
方法可以照搬。**读不懂这三段，动态分析就只是空谈。**

### 案一：7 岁丧母（p37）

袁氏自述：「六岁前坦然」，「7 岁入申运，流年丁亥，八月母亲去世」。
他自己给的解释是「四孟齐逢冲至」——寅申巳亥四个长生字互冲。

**陆氏先肯定后补刀**：「当然，这是不错的解释。但为什么发生在娘亲身上？命批没有作出交代。」

他自己的断法，两步：

1. **流年丁亥 与 年柱辛巳 天地冲**（丁克辛、亥冲巳）；
   同时**大运申 与 命局时支寅 六冲** → 命局大动，是"动"的信号
2. **星宫定位**：八字缺水，**水为印星，联络着母亲**；缺印星而骤然引发冲克，
   且**年支也是母亲的宫位**，流年巳亥冲正是"冲母宫" →
   「"冲母"的"应期"到了」

外加一层辅助：运限上**月柱纳音（山下火）克年柱纳音（白蜡金）**，
年柱是祖上父母的宫位 → 预示初年六亲受损。

> **方法提炼**：只断"冲"不够，必须用**星（印=母）+ 宫（年支=母宫）**锁定具体六亲。
> 否则只能说"家里有事"，说不到是谁。

### 案二：21-30 甲午运，完姻连得二子（p38）

- 甲木扶持日主 → 日主强了**才能担得起财**；**财星为妻** → 故有婚庆
- 甲木「引动」时支**寅**（寅是甲之禄），而**寅处于子女宫位** → 连得二子
- 局中**七杀为子星**，透出年干、通根月令、甚旺 → 理应多子

> **方法提炼**：一条运里婚姻与子女同应，是因为这个字同时踩中了财（妻）与子息宫/星。
> **看"这一个字同时动了谁"**，比分开看有效率得多。

### 案三：丙午年（41 岁）父亲与次子同月相继亡故（p39）★

这是最精妙的一段。袁氏自己的解释是「丙辛化水反击丁火，小限癸巳」，**陆氏明确表示不同意**，
另给了一套推理：

```
流年丙火 → 引动它在原局的两个「禄」——巳火（丙禄在巳）
        → 于是解开了原先巳酉之合的牵制，还原巳火原性
        → 变成两个巳火左右夹击酉金
        ↓
酉金被夹击 → 天干辛金七杀失去根基，由强转弱
丙火（食神）平添能量，进一步制辛金
丙辛相合 → 通禄的丙火进一步合制辛金
        ↓
原先强盛的辛金七杀，落到【干支俱损】
同时：大运甲木生丙丁火；流年午火与命局时支寅【半合火局】
        → 整个命局一片熊熊火海
        ↓
【辛金之位在年干，也是父亲宫位】 → 慈父难逃
【七杀辛金又是子星】           → 次子命黄泉
```

原书原话：「辛金之位在年干，也是父亲宫位，自然慈父难逃劫数；
七杀辛金又是子星，命主次子也命黄泉。」

> **方法提炼**：**同一个字可以同时是"星"和"宫"**。辛金既是七杀（子星），
> 又坐在年干（父宫）——它一倒，父与子同时应。
> 找到这种"星宫重叠"的字，往往一击两中。

### 三个案例共同的方法骨架

```
① 找引动：大运流年哪个字动了原局？（同字、禄位、合、冲、半合）
② 看程度：被动的字是"由强转弱"还是"干支俱损"？（不是非黑即白）
③ 定六亲：用「星」定是谁，用「宫」定在何处；星宫重叠者最重
④ 定时点：哪一年动、哪一柱宫位被冲，就是应期
```

**四步缺一不可。** 只到①就是袁氏说的"四孟齐逢"，热闹但不知道应在谁身上。

### 术语：什么叫「应局」与「应期」（p36）

> 「这是动态描写中的「应局」现象，即**运岁干支引动原局成分，发生作用，
> 构成了「应期」**。」

- **应局** = 运岁干支把原局某个成分"激活"的过程
- **应期** = 被激活后具体落到的那一年

书中还点明互动的纽带：「**原身与禄的关系**，它是大运、流年与原局成分
发生互动的重要纽带」（详见《进阶教程》）。所以看到"甲年动寅""丙年动巳"，
走的就是原身—禄这条线。

### 引动的两个方向（第八章 p262-263）★

原书用两个案例点出，引动是有方向的：

**① 运岁地支 → 引动原局天干**（靠禄位牵线）

> 盲派命例：行**戊寅**运。「戊为日主（到达），**寅为甲的禄**，等于自己坐着七杀，
> 所以此运当了副市长。而且此杀有化，**寅午合了印局**，等于权力到了。」（p262）

陆氏的解释：戊土日主在地支有两个强根、又得丁火之助，日主不弱；
局中伤官生财、财生杀，杀为官位。戊寅运的**寅**是甲木的禄，**引动了原局的甲木七杀**，
七杀正是喜神 → 此运升官。

> 「这是**大运地支引动了原局的天干**。」

**② 运岁天干 → 引动原局地支**（同样靠禄位）

原书紧接着又给一例，结论是：

> 「这是**流年天干引动了原局的地支**。」（p263）

前面袁树珊丙午年那个案例走的正是这一路——**丙火（天干）引动原局的巳火（丙禄）**。

**用法**：拿到一步运/一年，不要笼统说"这年有动静"，先问：
**是它的天干在动原局的地支，还是它的地支在动原局的天干？**
动了哪个字、那个字是喜是忌，应期就清楚了。

## 十二、动态分析的操作顺序

```
1. 先把原局破完（强弱→调候→格局→刑冲→形象），得出一组"核心用神与忌神"
2. 排出大运，看每一步大运是加强还是破坏这组用神/忌神
3. 在关键大运里扫流年，找引动点（合、冲、伏吟、反吟、扭曲）
4. 区分"背景"与"触发"：大运定基调，流年定应期
5. 不要一年一年硬断——先找结构性的转折点
6. 落到具体六亲时，用「星 + 宫」定位，星宫重叠者最重
```

## 十三、常见坑

1. **见冲就断凶。** 冲忌神是好事；合能解冲；冲而不破者多。
2. **见合就断化。** 化格的条件很苛刻，《基础教程》第四章后段专门讨论过。
3. **只看原局不看大运。** "原局有伤官见官"不等于"一定坐牢"，
   李敖是丙火正官大运引动才应事的（《动态分析教程》p215）。
4. **流年单断。** 流年必须放回大运与原局里看，孤立看流年毫无意义。
5. **忽略反向推法。** 问"何时"和问"这一年如何"，推的方向是相反的（见第六节）。
